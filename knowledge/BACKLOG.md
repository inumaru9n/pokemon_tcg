基盤・ツール・調査タスクはここに入れず、必要になったタイミングで直接実施する。

状態: `proposed` → `in-progress` → `validated`（採用） / `rejected`（棄却） / `blocked`

- 新アイデアは必ず既存行との重複を確認してから追記する
- 検証したら状態とEXPリンクを更新する
- 優先度: 総合判断H/M/L。**効果**（勝率への上積み見込み）と**実現性**（実装の容易さ・確度）を2軸で別評価（proposedのみ記入、済みは—）
- 2軸の読み: 効果H×実現性Hが理想。効果Lは検証済み空間で着手非推奨、実現性Lは重量級長期投資

## 2026-07-20 アーキテクチャブレスト落選メモ（再提案防止）

ゼロベースで6家族17案を起草し既知の失敗機序と突き合わせた結果、上記I-122〜I-125以外は以下の理由で着手前に落選。同型案を再提案しないこと:

- **今ターン最大打点の厳密解（DP/ILP）** → 052サブ選択資産（攻撃対象100%/進化89%一致）と完全重複。埋める穴が無い
- **2ターン確定プライズレース証明（相手最悪ケースminimax）** → 真のminimaxは隠れ手札上ほぼ発火せず、決定化で近似した瞬間EXP-053の受動性バイアスが「勝ち確定」方向の偽陽性に化ける（lethalが安全なのは自ターン内で閉じるから）
- **階層プランナ（HTN/ゴールスタック/フェーズ状態機械）** → 実装・棄却済み（agents/065-067、プールv3 23-26%、[EXP-065](experiments/EXP-065.md)で事後文書化）
- **相手リスト事後分布推定/決定化サンプラ較正** → 消費先の手書きプレイアラウンド分岐は行動抑制7連敗の同型。lethal探索は580発火敗北0で精度改善余地ゼロ、SAMPLES=8で漸近済み（EXP-049）
- **CMA-ESでルール閾値最適化** → 052ルール層の管轄は今やサブ選択+フォールバックのみで低leverage（EXP-060基準）。同じ最適化予算はI-122のクラスバイアスへ
- **CFR/後悔最小化（I-054）** → 本番は固定分布ラダー+10%ランダム=搾取(best-response)が目的で均衡は目的でない。目的関数ミスマッチ
- **LLMルールパッチ生成×アリーナ統計ゲート自動ループ** → パッチ母集団=「モデルの上への手書きルール」で事前勝率1割未満、50候補回すと多重比較でEXP-070型偽陽性が2-3個出る=偽陽性の自動量産機。評価スループット（4コアIntel）の浪費
