## 仮説

本番勝率3位の新興アーキタイプBarbaracle（Majkel1337個体、226戦60.6%、対Starmie 66%）を
ローカルに移植すれば、現行ベスト036_starmie_lethalの弱点を突くスパーリング相手が得られる。
合格基準: **vs 036 で55%以上**（本番の対面表66%の再現度指標）。候補としての評価は副次。

## 方法

- **デッキ復元**: `data/episodes/2026-07-08/summary.csv` の deck_signature=35ce7e0e55 から60枚復元。
  中身は**全員非ルールボックスの闘単**: Okidogi 3 / Bloodmoon Ursaluna 1 / Lunatone 2 / Solrock 4 /
  Binacle 2→Barbaracle 2 + 闘エネ10 / Prism 4 + Neutralization Zone(ACE SPEC) / Battle Cage 3。
  コアギミック2つ:
  1. **Prism Energy→Okidogi**: たねポケにPrismは全タイプ扱い（エンジン実装 `State.h getEnergyInfo` で
     `EnergyType::All` を確認）→ Adrena-Power発動 = 230HP / Good Punch 170
  2. **Neutralization Zone**: 相手ex/Vのワザダメージを非ルールボックスに通さない。
     Starmieの打点はMega Starmie ex（+Cinderace 50のみ）なので対Starmieはほぼ完封
- **方策**: 004 islet骨格を書き換え（探索なし・自己完結）。実装前に**Majkel1337の全226戦リプレイを
  集計スクリプトで解析**（EXP-035逆設計の軽量版。個別精読はせず行動頻度の集計のみ）し、主要ルールを反映:
  - 先攻は常にYES（120/120）/ セットアップアクティブはSolrock優先（120>Okidogi 59）
  - アタッチ分布: Prism→Okidogi 605 / F→Okidogi 330 / F→Solrock 214 が支配的 → 採点で再現
  - 攻撃分布: Good Punch 1055 / Cosmic Beam 297 / Mad Bite 50 / **Hammer In 0**
    → Barbaracleはアタッカーでなく Stone Arms 加速エンジン（エネ採点を低く）
  - Lunar Cycle 989回 / Stone Arms 685回 → 特性は基本毎ターン発火（低デッキ・手札F1枚時はガード）
  - Battle Cage は自分のNZ上書き禁止（本番でも5回のみ）、相手スタジアム潰しに積極使用（Spikemuth Gym 47回）
  - NZは相手のex/megaEx（盤面or相手トラッシュ）を見たら3400で即出し
  - Mad Biteは 100+30×ダメカン のターゲット依存打点として実装、Ursaluna はレイト投入（手札F2枚時）
- 対戦条件: seed=42, -w 2。
  `uv run arena/run_match.py agents/037_barbaracle agents/036_starmie_lethal -n 400`
  `uv run arena/run_pool.py agents/037_barbaracle -n 200 --json arena/results/EXP-037.json`
  `uv run arena/run_match.py agents/037_barbaracle agents/034_marnie_top -n 200`

## 結論

- **仮説は支持された**。037は「本番の新興Barbaracle脅威を再現するスパーリング相手」として合格
  （vs 036 = 69.5% ≥ 55%）。**現行ベスト036はBarbaracleに構造的に弱い**（Neutralization Zone
  1枚でMega Starmie exの全打点が消え、コスパで押し切られる）ことがローカルでも確認された
- 副次評価: プールweighted 58.6%でvalidatedだが036の66.1%には届かず、**提出候補としては036が上**。
  Marnie系（シェア21.7%）に30-35%の構造的弱点があるため、メタがMarnieに寄るほど価値が下がる
- リプレイ「集計のみ」の軽量逆設計（個別精読なし、半日以下）でも、対面プロファイルを本番個体
  ±3ptで再現できた。EXP-035のフル精読（30ルール抽出）より大幅に安い
- INSIGHTS昇格候補:
  - 「036/035系Starmie単騎アタッカー型はBarbaracle（NZ+非ルールボックス闘）に構造負けする
    （037が69.5%）。本番でBarbaracleシェア（現4.3%）が増えたらStarmie続投はリスク」
  - 「軽量逆設計（リプレイ226戦の行動頻度集計→採点関数に反映）だけで本番個体の対面プロファイルを
    ±3ptで再現できる。フル精読（EXP-035）は必須ではない」
- 派生アイデア（BACKLOG追記は親に委任）:
  - **I-案: 036へのBarbaracle対策**: 036は非ルールボックス打点がCinderace（Turbo Flare 50）のみ。
    NZ下で唯一通る打点なので、対Barbaracle検知時にCinderaceを主砲化する対面テック
    （ただしgated対面テックは3連敗の実績あり、期待は薄い）
  - **I-案: 037自体のMarnie対策**: NZをSpikemuth Gymに潰されない出し順（相手のスタジアムを
    使い切らせてからNZ）や、Xerosic/Judgeの妨害寄せ。ただしアーキタイプ相性の壁が厚い
  - プールへの037追加を検討（Barbaracleシェア4.3-5.3%。本番勝率3位の新興で今後増える可能性）
