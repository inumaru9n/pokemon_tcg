## 仮説

模倣side のチューニングが出尽くした（EXP-070〜073全null）のは目的関数が一致率だから。
CRN（共通乱数）でペア評価の分散を対消滅させれば、**勝率そのものを目的関数**にした
オンポリシー較正（058のGBTクラスlogitへのバイアス、37クラス×山残量3バケット=111次元）で
真のコミット差±2-5%WR（EXP-053で実在確認）を回収できる。

## 方法

### Step0: エンジン決定化（キルゲート: バイト一致しなければ棄却）

- 配布ソース無変更のまま `cg/Export_seeded.cpp` が `Export.cpp` を取り込み
  `BattleStartSeeded(cards, seed)` を追加（config.seed指定+deviceRand=false+rng上書き削除。
  エンジンは元々 mt19937+deviceRand分岐の決定化機構を内蔵しており入口が無かっただけ）。
  ビルドコマンドはExport_seeded.cpp冒頭に記載。既存シンボル無変更=完全後方互換
- `cg/sim.py` に能力検出付きバインディング、`cg/game.py` に `battle_start_seeded`、
  `arena/run_match.py` に `--engine-seed`（per-game seed = f(base, game_index)）を追加
- 提出物には含めない（Kaggle環境は配布オリジナルcg同梱、能力検出で自然フォールバック）

### Step1: CRN分散縮小率の実測（キルゲート: R<1.3で棄却、<2で予算再計算）

- 058 と 079プローブ（全111次元に±0.2のRademacherバイアス=SPSAの1摂動相当）を
  同一エンジンシードブロック（base=999）で各400戦、対040(Alakazam)/038(Marnie)
- per-gameスコア x_i(058), y_i(079) から縮小率 R=(Var x+Var y)/Var(x−y) を算出

### Step2: SPSA本最適化（agents/079_058_crnopt/spsa_079.py）

- パラメタ: θ∈R^111 初期値0（=058と完全同一）、クリップ±0.6
- 目的関数: プールv3から**038を除外し正規化**した重み付きスコア率
  （045:40.4 / 047:13.0 / 041:7.4 / 042:4.3 / 007:3.7 / 035:3.6 / 046:3.0 / 021:2.1 / 000:10.2）
- SPSA: c_k=0.2/(k+1)^0.101, a_k=0.8/(k+6)^0.602、±評価は同一CRNシードブロック、
  ブロックはイテレーションごとに更新（単一シード集合への過適合防止）
- 約240戦/評価×2評価/iter、θは毎iterチェックポイント（spsa_log.jsonl、再開可）

### 事前登録の合否ゲート（Step2完了後。**一致率は合否に使わない**）

2. **最終ゲート**: vs 058 直接・**2シード×各800戦（非CRN=本番同条件）**で

## 結論

**rejected（中立）。ただし本実験の主要産物2つは恒久資産として残る。**

1. **クラス×山バケットの粗い系統補正の空間に、058から±2pt超の利得は存在しない**。
   SPSAは収束挙動（|θ|プラトー・勾配信号消失）を示した上で、最終θは全評価軸で058と
   統計的同等だった。CRN（測定失敗の言い訳が消えた状態）でのこの中立は情報量がある:
   EXP-016の「測れなくて不発」と違い、**「058のクラス優先度は粗い傾けに関して既に局所最適」**
   が正の知見。EXP-053の真のコミット差±2-5%は文脈依存で、クラス定数バイアスでは表現できない
2. **CRN評価基盤はvalidated・恒久資産**: エンジン決定化（cg/Export_seeded.cpp、バイト一致検証済み）
   + run_match --engine-seed。ペア評価で差分SEが半減（分散縮小3.9-4.3x実測）し、
   **今後の全ての候補vs基準比較を約1/4の戦数で同精度にできる**。11年来の「CRN不可」制約の解除
3. I-123（特徴量条件付き拡張）の事前登録済み着工条件「I-122で転移利得を確認」は**不成立**
   → I-123は着工しない（粗い空間の平坦は豊かな空間の平坦を証明しないが、段階投資の規律を優先）
4. 多重比較の規律: Polyak平均θや中間チェックポイントの事後評価は行わない（EXP-070の教訓）
