## 仮説

07-22メタで13.1%に急成長した Team Rocket's Spidops（トップ個体 d5834c603a、634戦53.5%）を
軽量逆設計（EXP-037方式）でレプリカ化すれば、既存プールにゼロだった同アーキタイプの相手役が得られる。
特に本番でAlakazam側が14%まで刺されている対面（Spidops側86%、n=277）の再現が忠実度の核。
合格ゲート: vs 045_alakazam_full が86%±5pt、vs 041_garchomp_replica が35%±5pt。

## 方法

- **デッキ復元**: `data/episodes/2026-07-22/summary.csv` の deck_signature=d5834c603a から60枚復元。
  **deck_ids はcardId直（1始まり）**。0始まり解釈だと別デッキに化けるので注意（Tarountula+Spidopsの
  進化ラインが揃うかで判別できる）。中身: 草エネ7 / 超エネ3 / Team Rocket's Energy 4（超悪2個分）/
  Tarountula 4 → Spidops 4 / Articuno 2 / **Mewtwo ex 2（280HP）** / Wobbuffet 1 / Murkrow 2 +
  Bug Catching Set 3, Poké Pad 4, Transceiver 4, Ariana 4, Giovanni 3, Proton 2, Archer 1, Petrel 1,
  Lillie 2, Energy Search 2, Night Stretcher 1, Hero's Cape 1, Brave Bangle 1, Factory(スタジアム) 2
- **デッキのコア構造**（エンジンデータで確認）:
  1. **Mewtwo ex の Erasure Ball 160 [P,P,C]**: ベンチのエネを最大2枚破棄で+60ずつ（最大280）。
     Power Saver（場に4匹以上いないと攻撃不可）があるため盤面は常にワイド展開
  2. **Spidops の Charging Up**: トラッシュの基本エネを毎ターン自身に回収 → Erasure Ballの
     破棄フォダーが実質無限ループ（破棄→回収→破棄）
  3. **Rocket Rush [G,C] = 30×自分のロケット団ポケモン数**（全員ロケット団なので盤面数×30、最大180）
  4. **Articuno の Repelling Veil**: 相手ワザの「効果」を自分の**たね**ロケット団全員に対して無効化
- **方策**: islet骨格（004/037系）に、d5834c603a のリプレイ302戦（対Alakazam全152戦+他150戦）の
  行動頻度集計を焼き込み。主要ルール: 先攻常にYES(160/160) / セットアップはMewtwo・Murkrow優先 /
  エネ貼り分布はG→Mewtwo 448, TR→Mewtwo 382, P→Mewtwo 381, G→Spidops 317 / Charging Up 713回・
  Factory 314回は毎ターン発火 / 攻撃はErasure Ball 891 > Rocket Rush 501 > Deceit 155 /
  Ariana は手札1-5枚で使用（全員ロケット団なので8枚まで引く）/ Giovanni のガスト先は
  Fezandipiti ex・Dudunsparce・Abra（瀕死ex釣り出し or 無力ポケモンで壁）
- **対Alakazam 86%の勝ち筋**（episode 87366420 精読）: Alakazam の Powerful Hand はダメカン配置=
  「効果」なので **Repelling Veil 下のたねロケット団（Mewtwo含む）に文字通り0**。Alakazam側の
  実ダメージ源が Kadabra 30 と Cruel Arrow（ベンチ狙撃100）だけになり、280HPのMewtwoが
  Erasure Ball 160-220 で盤面を順に一掃する。Archer（相手手札→3枚）が Powerful Hand の打点も削る
- **補正1（Garchompゲート初回22.5%で発動、EXP-039手順）**: 本番勝ちトレース（87370631）精読で
  「**Garchomp ex は草弱点 → Rocket Rush 30×6×2=360 が330HPをワンパン**、1サイドのSpidopsを
  差し出して2サイドと交換」が本線と判明。ベンチアタッカーの手貼り先読み許可＋弱点込み打点概算での
  昇格/Giovanni判断を実装 → 32.5%
- **補正2（対038が18.0%で発動）**: ローカル対戦ログで「空のMewtwo（悪弱点、Shadow Bullet 180×2=360で
  ワンパン）を繰り返し前に出して2サイドずつ献上」を確認。Grimmsnarl ex も草弱点（Rocket Rush圏内）。
  相手盤面のワザ表記ダメージ×弱点で被ワンパン推定し、2サイド個体の昇格に強ペナルティ → 35.5%
- 対戦条件: seed=42, -w 2。
  `uv run arena/run_match.py agents/083_spidops_d583 agents/045_alakazam_full -n 400`
  `uv run arena/run_match.py agents/083_spidops_d583 agents/041_garchomp_replica -n 400`
  `uv run arena/run_pool.py agents/083_spidops_d583 -n 200 --json arena/results/EXP-083.json`

## 結論

- **仮説は支持された**。083は「本番の新興Spidops脅威（特にAlakazam搾取）を再現するプール相手役」として
  合格。プールへの追加を推奨（07-22シェア13.1%。次回pool.json更新時に組み込み、weighted比較の切断に注意）
- **Alakazam系候補への警告**: 現行プール1位枠のAlakazam系（045系統の方策）はSpidopsに構造負けする
  （本番14%、ローカル7-10%）。Powerful Hand主体である限り Repelling Veil で無力化される。
  Spidopsシェアがさらに伸びるとAlakazam系主力候補の期待値は大きく下がる
- 軽量逆設計の追試: 頻度集計だけの初版はゲート2/3不合格。**「負けトレース（または本番勝ちトレース）
  1-2本の精読→弱点ルール補正」のループが±5pt到達に必須だった**（EXP-039と同じ結論。今回は2周）。
  効いた補正はどちらも「弱点倍率を織り込んだアタッカー選択/昇格」で、頻度集計では出てこない
- INSIGHTS昇格候補:
  - 「Team Rocket's Spidops（07-22シェア13.1%）はAlakazamの構造カウンター: Powerful Handのダメカン配置は
    『効果』なので Articuno の Repelling Veil でたねロケット団に0になる（本番86%、083が90-93%で再現）」
  - 「summary.csv の deck_ids は cardId 直（1始まり）。0始まりで引くと別カード列になるが偶然60枚の
    もっともらしいデッキに見えるので進化ライン整合で必ず検証する」
- 残課題:
  - **vs 047_kangaskhan 24.0% は ladder 61%(n=89) から-37pt**。既知のレプリカ間対面乖離パターン
    （EXP-042/047: 壁・対面特化知識で±14-35pt）の最大級。083をKangaskhan系候補の評価に使う場合は
    本番対面表61%を正とすること。Spidops側の対Kangaskhan固有シーケンス（未精読）が欠けている可能性
  - vs 035_starmie 6.5% は ladder参照なし（Starmie系シェア縮小でn不足）。解釈保留
  - 兄弟sig 7725a404d1（324戦54.9%、勝率はd583より上）は未レプリカ化。プール枠の代表交代余地あり
