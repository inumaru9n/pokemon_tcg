# EXP-134: LayerNorm と深さ — 容量は飽和ではなく過剰だった

- 日付: 2026-08-14〜15
- 対象: 186（L2・正規化なし）に対し **内部正規化（LayerNorm）** と **深さ** を振る
- 状態: **LayerNorm は棄却。深さの削減（L2→L1）は採用**（+0.51pt、EXP-136 の土台）

## 1. 経緯

EXP-121 は「layers 3 が明確に悪化した」ことを
**「ネットワークに内部正規化が一切ないため深くできない」** と診断していた。
しかし**その対処（LayerNorm を入れる）は一度も試していなかった**。
並びは `Linear → ReLU → LayerNorm → Dropout`、LSTM出力にも `h_norm` を置く。

## 2. 結果（pool v7・n=1200/相手・9相手・CRN engine-seed 20260809）

| 構成 | エージェント | プール | 平均 |
|---|---|---|---|
| **L2・正規化なし** | 186 / 217 / 218 | 71.25 / 70.94 / 70.61 | **70.93%** |
| L2・**LayerNormあり** | 211 / 212 | 70.33 / 70.28 | **70.31%** |
| **L1・正規化なし** | 214 / 219 / 220 | 71.47 / 72.13 / 70.74 | **71.45%** |
| L1・**LayerNormあり** | 213 / 215 / 216 | 71.09 / 71.53 / 71.28 | **71.30%** |

**シードを揃えた対応差:**

```
**LayerNorm の効果**
   L2 で  s1 −0.92 / s2 −0.66            → **−0.79pt**
   L1 で  s1 −0.38 / s2 −0.60 / s3 +0.54 → **−0.15pt**（sd 0.60、有意でない）

**深さの効果（正規化なし、L1 − L2）**
   s1 +0.22 / s2 +1.19 / s3 +0.13        → **+0.51pt**
```

## 3. ★ val は上がるのにプールは下がる（この関係の初出）

```
186（L2・正規化なし）     val 0.8648 / 0.8662   プール **71.25%**
186+LayerNorm（L2）      val **0.8703 / 0.8704**   プール **70.31%**
```

**val +0.42pt に対してプール −0.94pt。**
「保持データでの教師再現度」と「対戦の強さ」が**逆方向に動く**ことを初めて実測した。
この関係はその後 **EXP-140 で t=12.4 という強い val 差でも再現**した
（L0: val +0.62pt → プール −1.16pt）。

## 4. ★ 深さは単調 — 容量は飽和ではなく過剰

LayerNorm ありの構成で深さを振ると、val が**単調に減少**した。

```
**L1 0.8718 > L2 0.8703 > L3 0.8696 > L4 0.8682**
```

L1 は **790,531 パラメータ = 186 の 60%** なのに val 最良（MAIN 0.8411）。
EXP-121 の「正規化が無いから深くできない」という診断は誤りで、
正しくは **そもそも深さが要らなかった**。

この発見が2つの実験を生んだ:
- **EXP-136**: 容量が適正なら**シード間の誤差が独立になる**→ 確率平均アンサンブルが
  +1.06pt（EXP-117 は L2 で棄却していた）
- **EXP-140**: 単調なら **L0（再帰なし）はどうか** → val +0.62pt だがプール −1.16pt で棄却

## 5. ★ 比較は同一シード群で行う

v4 までは**ベースライン186が1シード（=s1）なのに候補は3シード**という不公平な比較だった。
186 の提出重みは3シードの最良個体（71.25 vs 平均 70.93）＝**上振れ**で、
これを基準にすると候補の利得が過小評価される。

以後、**主対比は同一シード群で3本ずつ**に統一した
（この規律が EXP-139 の「同一runで交互順」に発展した）。

## 6. 教訓

> **既存の診断を疑う前に、その診断が示す対処を実際に試す。**
> EXP-121 の「正規化が無いから深くできない」は、対処（LayerNorm）を試して初めて
> 誤診と分かり、正解（深さが要らない）に到達した。

> **val の改善は採否の根拠にならない。**
> LayerNorm は val を +0.42pt 上げてプールを −0.94pt 下げた。
> 以後、**プールを主判定に置く**運用に変えた。
