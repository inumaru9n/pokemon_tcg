# EXP-030: Iron Thorns ex 能力ロック軸（Initialization lock）

- 日付: 2026-07-08

## 仮説

Iron Thorns ex(37) の特性 Initialization（バトル場にいる限り双方のルールボックス特性を全停止、Future除く）で、メタ上位の特性依存デッキ（Marnie の Punk Up、Mega Starmie / Alakazam 系）のエンジンを止めれば、デッキパワー差を覆せるのではないか。2024年 Worlds 実証の妨害アーキタイプ。既知のリスク: 闘弱点×Lucarioメタ（Mega Brave 270×2=540 でワンパン）は織り込みで実測する。

## 方法

- カード調査（`cg.api`）:
  - Iron Thorns ex(37): HP230・雷・にげる4・弱点闘。Volt Cyclone [L,C,C] 140、攻撃のたびエネ1個をベンチへ移動（次のアタッカーを自己充電）
  - エンジン実装確認: CardImpl.h L250 `effectNoAbility(Both).targetRulePokemon().targetCondition(TargetType::Future, NotEqual)` — ロックは正しく実装されている
  - Future 系の仲間: Miraidon(87, Peak Acceleration [C] 山札から基本エネ2枚をFutureに加速)、Iron Crown ex(80, Cobalt Command: Future の攻撃+20、Future なので自分のロック下でも生きる)。Iron Hands / Jugulis / Valiant はカードプールに不在
  - 注意: Reboot Pod(1089) は ACE SPEC（Hero's Cape と併用不可。初回スモークで errorType=4=ACE SPEC重複を踏んで判明）
- デッキ60枚: Thorns×4 / Miraidon×4 / Crown×2 / 雷エネ×12 / Carmine×4 / Lillie×4 / Judge×3 / Boss×4 / Ultra Ball×4 / Dusk Ball×4 / Switch×4 / Crushing Hammer×4 / Night Stretcher×2 / Levincia×2（雷エネ回収スタジアム、相手は雷不使用で片利）/ Energy Retrieval×2 / Hero's Cape×1(ACE)

### ロック機能の実測検証（vs 002、40戦の計測）

ロック自体は設計通り機能している:

- Thorns アクティブ率（自分の選択ステップ基準）: **66.4%**
- 相手の Grimmsnarl ex 進化 193 回のうち、ロック中 132 回の同ターン悪エネ加速は **平均0.48枚**、ロック外 61 回は **平均3.31枚** — Punk Up をほぼ完全に止めている

**それでも 26% しか勝てない。** 敗因はロックの不発ではなくデッキの地力:

1. **打点が遅い**: Volt Cyclone 140（Crown 2体で180）は Grimmsnarl ex(320) に2〜3発、Mega 系(350+)に2〜3発。相手は 180/turn（Shadow Bullet [D,D]）で Thorns(230) を2発
2. **Punk Up 停止の効果が小さい**: Grimmsnarl の攻撃コストは [D,D] だけ。手貼り2回で起動でき、加速停止はテンポ1ターン分の遅延にしかならない
3. **プライズ経済が最悪**: 場が全部ルールボックス（2枚取り）。相手は3KOで6枚、こちらは140打点で2〜3ターン/KO
4. vs 007 は予告通り構造的壊滅（3.5%）: 闘弱点で Mega Brave 270×2=540、Hero's Cape(330) でも受からない
5. vs random でも 89.5%（004 は 99%）— OHKO 手段のない低速デッキは事故+引き分けレースでランダム相手ですら取りこぼす

## 結論

- 仮説は**支持されなかった**。特性ロックはメカニクスとしては完璧に機能する（エンジン実装も正しい、Punk Up 7分の1に抑制）が、このカードプールの上位デッキは「特性を止められても素のアタッカー性能だけで勝てる」構造。ロックで得るテンポ1ターン < 打点2倍差+闘弱点、で全対面負け越し
- 妨害単体はアーキタイプとして成立しない。ロックが刺さる前提は「相手が特性なしでは攻撃を組み立てられない」ことだが、pool の全デッキは手貼りだけで主砲が起動する
- 自作デッキ+自作方策の弱さ（INSIGHTS既知）も重なるが、vs 007 3.5% / 全対面 CI 上限が 44% 未満なので方策磨きで覆る差ではない
- 派生アイデア: なし（この路線は閉じる）
