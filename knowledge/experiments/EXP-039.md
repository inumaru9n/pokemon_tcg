## 仮説

07-08 ladderのMega Kangaskhanトップレシピ（sig 89d834e4d4、534戦55.1%、bono/Raihan Ramadistra他
5名が使用）を軽量逆設計（EXP-037/038の行動頻度集計）で移植すれば、038_marnie_replicaの

合格基準: **vs 038 で65%以上**（本番対面のKangaskhan側≈80%の再現度指標）。

## 方法

- **デッキ復元**: `data/episodes/2026-07-08/summary.csv` の deck_signature=89d834e4d4 から60枚。
  Mega Kangaskhan ex 4（300HP・Rapid-Fire Combo 200+コイン・Run Errandドロー2）/
  Dwebble 3→Crustle 3（**Mysterious Rock Inn: 相手ex/megaExのワザダメージを完封する壁**、
  Superb Scissors 120 は「相手バトル場の効果を無視」）/ エネは特殊12+G1
  （Mist=効果防止・Spiky=反撃2個・Grow Grass=G供給+HP20/枚）/ Jumbo Ice Cream 4（3エネで80回復）/
  Boss 4・Petrel 4・Hilda 3・Lillie 4・Eri 2 ほか。**アタッカーとエンジンが同一カード**で、
  勝ち筋は「対ex: Grow Grassスタック+Cape+IceCreamの不沈Crustleで削り勝ち / 対非ex: Kangaskhan 200連打」
- **方策**: 037と同じくislet骨格を書き換え。全534戦のリプレイを行動頻度集計
  （scratchpad/aggregate_039.py, aggregate_039b.py）して反映した主ルール:
  - 先攻YES 239/246 / セットアップアクティブ Kangaskhan>Dwebble（pairwise 77:42）
  - **攻撃者の使い分けが核心**: 相手盤面にex/megaExがいる時のアタッカーは Crustle 1190 : Kangaskhan 264、
    非exデッキ相手は 396 : 353 → opp_rulebox で Crustle/Kangaskhan の攻撃ボーナスを切替
  - Run Errand 毎ターン発火（1579回、デッキ≤2のみ抑制）/ Dwebble→Crustle 進化即時（709回）+
    Ascension でデッキから進化（214回）/ Poffin は実質Dwebble専用（680回）
  - エネ: Grow Grass→Crustle系（Gコスト+HPスタック）、Mist/Spiky→Kangaskhan、
    Cape→Crustle/Kangaskhan、Fan→Kangaskhan
  - Bossはキル専用（killable 608 : tank 43）。対MarnieはMunkidori狙い105回
  - Hildaのサーチ先は Crustle 438 + エネ / Petrelの取り先は IceCream>Cape>Poffin>Switch /
    Pokégearは Boss>Petrel>Lillie / リトリートは534戦で6回のみ（移動はSwitchアイテム、256回）
- **初版の失敗と3修正（重要）**: 頻度焼き込みだけの初版は vs 038 = 50.7%（400戦）止まり。
  敗戦トレースで「ベンチにKangaskhan 3体（=9プライズの的）を並べ、Shadow Bulletスナイプ+Bossで
  取り放題」「エネが分散して6ターン無攻撃」を確認し、
  (1) **Kangaskhanは盤面1体まで**（2体目はT6以降/非ex相手のみ、セットアップベンチも最大1）
  (2) **対exはCrustle系へ集中充電**（Kangaskhanへの手貼りを大幅減点）
  (3) **攻撃不能ターンはSwitchでKangaskhanを壁Crustleへ退避**
  の3修正で 70.5%（200戦、seed42）に改善。本番個体の「手出しKangaskhanは median T8・約1.6体/戦」
  という展開抑制は頻度表の集計だけでは見えず、負けリプレイの精読相当が必要だった
- 対戦条件: `-w 2`。スモーク20戦(errors=0) → **vs 038 400戦 seed7（チューニングに使ったseed42とは別）** →
  vs 036 200戦 / プール200戦 / 037・022 各200戦

## 結論

- **仮説は支持された**。039は「038の本番最大弱点（対Kangaskhan 21.3%）を再現するスパーリング相手」
  として合格（73.0% ≥ 65%。038元個体の裏返し78.7%に対し-5.7pt）。038を提出主力にする場合の
  弱点検証・対策開発（Crustle壁の突破手順）に使える
- プール49.3%で**提出候補ではない**（037と同じ「相手役専用」の位置づけ）。Kangaskhanアーキの
  本番強さ（55.1%）はladder個体の壁対応力の低さに依存しており、壁貫通を知っている相手
  （007/002/037）には脆い
- **軽量逆設計の限界が1つ判明**: 行動頻度の集計は「何をするか」は写せるが「何をしないか
  （Kangaskhanを2体目以降並べない等のリソース抑制）」を写せない。壁/タンク型デッキでは
  展開抑制が本質で、負けトレースの確認1回と3修正で50.7%→73.0%の20pt差になった。
  頻度集計＋負けトレース1本の確認をセットにするのが今後の標準手順
- INSIGHTS昇格候補:
  - 「038 Marnieトップレプリカの対Kangaskhan弱点はローカルで再現済み（039が73.0%）。
    機構はRock Inn壁でShadow Bullet完封+回復スタック。038対策/強化は貫通打点（Adrena増・非ex）で」
  - 「軽量逆設計は行動頻度で写らない**展開抑制**（多プライズ機の出し惜しみ）が壁型デッキの本質。
    頻度集計に負けトレース1本の精読を足すのが標準（50.7→73.0%）」
- 派生アイデア（BACKLOG追記は親に委任）:
  - 038の対Kangaskhan対策テック: 039をスパーリングに、Munkidori温存（Boss避け）・Adrena集中で
    Crustleを落とす手順の焼き込み（ただしgatedテックは3連敗の前例あり）
  - 036/038の対Barbaracle・対Kangaskhan共通課題は「非ex/壁への貫通打点」。デッキ側での解決
    （非exサブアタッカー枠）はEXP-013の枠経済制約に注意
