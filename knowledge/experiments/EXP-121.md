# EXP-121: 容量スイープ（d_model / layers / d_opt）— アーキ7連敗目

- 日付: 2026-08-10
- データ: 165（541次元・435,150決定）。同一データ・同一エポック数(60)・cosine
- 状態: **rejected（判別不能）**

## 動機

EXP-117 の監査では d_model 384 が 256 と同値だったが、それは104のデータ
（506次元・355,621決定）での**1本のみ**。165はデータが+22%あり、
**layers と d_opt は一度も振っていなかった**（`d_opt` は引数化すらされておらず、
`d_model` を上げても64のままだった）。

## 事前登録した判定基準

```
アンカー = 165本体の s1=0.8671 / s2=0.8637  → **シード幅 0.34pt**
**0.5pt以上のval改善がなければ差なし**と判定する
```

## 結果

| 構成 | d_model | layers | d_opt | val | MAIN | 訓練−検証差 |
|---|---|---|---|---|---|---|
| base | 256 | 2 | 64 | 0.8663 | 0.8345 | +0.0346 |
| m384 | **384** | 2 | 64 | 0.8657 | 0.8332 | +0.0637 |
| **L3** | 256 | **3** | 64 | **0.8616** | 0.8270 | +0.0300 |
| opt128 | 256 | 2 | **128** | 0.8690 | 0.8339 | +0.0541 |
| **wide** | **384** | 2 | **128** | **0.8704** | **0.8373** | +0.0525 |

```
wide − base   = +0.41pt
wide − 165s1  = +0.33pt   ← **シード幅0.34ptと同等** → 判別不能
```

- **layers 3 は明確に悪い**（0.8616、他より0.5〜0.9pt低い）。
  ネットワークに**内部正規化（LayerNorm/BatchNorm）が一切ない**ので、深くすると学習が悪化する
- d_model 384 単独は同値（EXP-117の結論がデータ+22%でも変わらない）
- d_opt 128 は +0.27pt だがシード幅の範囲内

## 判断

**容量は飽和している。** LayerNormの追加も検討したが、**L2の時点で d_model も d_opt も
効かない以上「正規化がなくて深くできない」ことは律速ではない**ので見送った。

これでアーキテクチャ・HPは**7連敗**:

| 実験 | 内容 | 結果 |
|---|---|---|
| EXP-097 | dropout / wd | 0.2で頭打ち |
| EXP-098 | MAIN階層の合成形 | 効果なし |
| EXP-113 | 選択肢間 self-attention | 49.2% 判別不能 |
| EXP-113 | focal loss γ=2 | 52.0% 判別不能 |
| EXP-117 | 3本アンサンブル | val +0.86pt → **プール ±0.00** |
| EXP-117 | d_model 384 | 同値 |
| **EXP-121** | **layers 3 / d_opt 128 / 併用** | **判別不能（L3は悪化）** |

EXP-117 の「**残差は分散ではなくバイアス**」（学習シードを変えた3本が同じ間違いをする）
という結論と完全に整合する。**容量を増やしても、教師データと特徴表現が決めている
系統的な誤りは減らない。**
