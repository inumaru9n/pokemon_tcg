## 5. Gravity Mountain（126/127）— **棄却**

### 設計（事前検証は全て通した）

GM = 場のStage2ポケモン（両者）が −30HP。非ACE、メタ採用率0.3%。

```
相手 Grimmsnarl ex  320 → 290（我々の実測平均打点290と一致＝1撃圏に入るはず）
     Garchomp ex    330 → 300 / Dragapult ex 320 → 290
     Mewtwo ex・Mega Kangaskhan ex は Basic ＝影響なし
我々 Alakazam       140 → 110（相手主力は180/160/200/260＝元から1撃、と判断した）
副次効果: 117はスタジアム0枚で Marnie の Spikemuth Gym 4枚
         （毎ターン無料でMarnie'sポケモンをサーチ）を剥がせなかった。GMが上書きする
```

事前検証: FEAT_KEYS一致 ✓ / smoke 20/20 ✓ / **語彙外でも方策が場に出す（73%の試合）** ✓ /
**エンジン上で Grimmsnarl ex の maxHp 320→290 を実測** ✓

### 結果

| | vs 117 直接（n=1200・CRN） | プール加重の対応差 |
|---|---|---|
| 126（GM 1枚） | **38.2%** [35.5-41.0] ❌ | **−3.20pt** [−6.27, −0.13] ❌ |
| 127（GM 2枚） | **31.0%** [28.4-33.6] ❌ | **−3.41pt** [−6.67, −0.15] ❌ |

対面別（127−117）: **Marnie −4.0（狙った対面が悪化）** / Alakazam −7.0 /
**Dragapult −13.8** / Spidops +1.2 / Kangaskhan +1.8

### 死因: 「主力の打点だけ」を見て HP を下げた

「Shadow Bullet 180 なので 140→110 でも元々1撃＝実害なし」という推論が誤り。

```
Marnie の他の攻撃役: Munkidori/Mind Bend 60、Marnie's Morgrem/Corkscrew Punch 60
   140HP → 60×3回 で落ちる
   110HP → 60×**2回** で落ちる     ← 必要回数が減る
```

**主力の打点が「110〜139の危険帯」に無いことだけを確認し、
蓄積ダメージと小打点攻撃の必要回数の変化を見ていなかった。**
Dragapult −13.8 も同じ機序（Dreepy/Drakloak の小打点が効くようになる）。

狙いの「320→290で1撃圏」も効かなかった。**平均打点290は平均であって、
実際に290以上出るのは試合の半分**。

> **教訓: 自分のHPを下げる効果は「一撃で死ぬか」でなく「何回で死ぬか」で評価する。
> 相手の最大打点だけを見た安全確認は不十分。**
