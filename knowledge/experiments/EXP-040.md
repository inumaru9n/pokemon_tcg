# EXP-040: Alakazamトップ個体（sig a73706e527）の軽量逆設計レプリカ

- 日付: 2026-07-10
- BACKLOG: I-078（の一部。Alakazam枠）
- エージェント: `agents/040_alakazam_replica/`
- 状態: validated（プールweighted CI下限>50%、かつ主目的の「自作010超え」を400戦74.2%で達成）

## 仮説

メタシェア1位（31.6%）のAlakazamについて、本番トップ個体のリプレイを軽量逆設計
（EXP-037/038の行動頻度集計手法）すれば、(a) 自作の010_alakazamを直接対決で超え、
(b) プールの最重要枠であるAlakazam対面の基準を本番個体品質に引き上げられる。

個体選択: 既定の a73706e527（THIRD PTCG Club、272戦53.7%）を採用。
比較候補 6a0dd41a46（capbloo、104戦57.7%）はリプレイ数が1/3以下で、
かつ対Marnie 34.8%と平凡（a737は70.8%でアーキタイプ平均36-39%に対し異例に強く、
レプリカ価値が高い）。

## 方法

- **デッキ復元**: `data/episodes/2026-07-08/summary.csv` の deck_ids から60枚。
  Abra/Kadabra/Alakazam 4-4-4 + Dunsparce/Dudunsparce 3-3 + Fezandipiti ex 1、
  Dawn 4 / Hilda 4 / Boss 3 / Xerosic 1 / Lana's Aid 1、Poffin 4 / Poké Pad 4 /
  Enhanced Hammer 4 / Rare Candy 3 / Night Stretcher 2 / Sacred Ash 1 / Tool Scrapper 1、
  Battle Cage 2、Telepath 4 / P 2 / Enriching(ACE SPEC) 1。
  010と比べ: Zam+1/Hammer+1/Boss+1/Stretcher+1/Xerosic/Lana/Scrapper追加、
  Lucky Helmet 3/Genesect/Psyduck/Shaymin/Battle Cage 2枚分を削除した形
- **方策**: 010_alakazam の骨格をベースに、全272戦リプレイの行動頻度集計
  （scratchpad/aggregate_040.py、obs=steps[i]とaction=steps[i+1]のペアリング）で
  判明した癖を焼き込み:
  1. **Powerful Handは使えるターンは必ず撃つ**（fire 1344 / hold 0。致死1191・非致死でも153撃つ）。
     手札を増やし切ってからターン最後に発射（平均手札15.4枚=308ダメージ、89%が致死）
  2. **Fez ex / Dudunsparceのドロー能力は毎回使う**（395回/327回）。010の
     「キルに必要な時だけ」ゲートを撤廃。ACTIVATE系はdeck≤5でのみNO（本人実測60%拒否と一致）
  3. **サーチ系（Poffin/Poké Pad/Dawn/Hilda/Telepath）の山札残数ゲートを撤廃**
     （ドローしないので山札切れに寄与しない。010の safe_draws=deck-prizes-1 は過剰に保守的）
  4. **Battle Cageは空スタジアムでも即置き**（本人はturn1-5で置く。ベンチのAbraを
     Adrena-Brain等のダメカン置きから守る=対Marnieの構造対策）。010はDragapult検知か
     相手スタジアム潰しのみだった
  5. **サポート優先: Boss(キル限定3400) > Xerosic(相手手札4+で3300) > Lana's Aid(回収2+)
     > Dawn/Hilda**（ペアワイズ: Xerosic>Hilda 204:54、Lana>Hilda 155:67。
     Bossはgust対象の92%がそのターンPH処理可能=キル専用）
  6. **セットアップアクティブ Dunsparce > Abra > Fez**（128:124、pairwise 48:4。010はAbra先頭）、
     ベンチは全部置く
  7. エネルギーは1体1枚（重ね貼り1%未満）、Enriching→Dunsparceライン/Fezのみ、
     昇格はAlakazam最優先・Dudunsparce/Fezはベンチ温存、相手Xerosic時の捨て順も頻度準拠
- **スモークで発覚したバグ3件**（初版は対random 89%に低迷）: (a) Enrichingのフォールバックが
  Abraラインに{C}エネを貼り、{P}コストのPowerful Handが永久起動不能に（1体1枚ルールで
  P貼り直しも拒否→無攻撃のまま山札切れ負け）。(b) P補充が「エネ0枚」条件でC汚染個体に
  貼れない。(c) リトリート判定が field_counts（アクティブ自身込み）でベンチアタッカー不在でも
  下がる。3件修正で対random 96%→98%
- 対戦条件: `-w 2`, seed=42（vs 007追試のみ seed=7）
  ```
  uv run arena/run_match.py agents/040_alakazam_replica agents/010_alakazam -n 400 -w 2
  uv run arena/run_match.py agents/040_alakazam_replica agents/036_starmie_lethal -n 200 -w 2
  uv run arena/run_match.py agents/040_alakazam_replica agents/038_marnie_replica -n 200 -w 2
  uv run arena/run_pool.py agents/040_alakazam_replica -n 200 -w 2 --json arena/results/EXP-040.json
  uv run arena/run_match.py agents/040_alakazam_replica agents/007_lucario_lethal -n 400 -w 2 --seed 7
  ```

## 結論

- **仮説(a)(b)ともに支持**。軽量逆設計の3個体目（037 Barbaracle→038 Marnie→040 Alakazam）で、
  同一アーキタイプの自作010を400戦74.2%で大差更新。プールweighted 65.3%でvalidated
  （036の66.1%、038の70.7%と同帯。ただし各プールの同居構成が違うため横比較は参考値）
- **主用途はプールのAlakazam枠の交代**: メタシェア1位31.6%の対面基準が「弱すぎる自作」から
  本番トップ個体レプリカに上がる。既存エージェントの対Alakazam成績は総じて下方修正される
  見込み（007: 53.5%→39.5%、038: 82%→未測定）
- バグ3件の教訓: **特殊エネルギーの供給タイプ（Enriching={C}）と攻撃コスト（PH={P}）の
  不一致は「一度も攻撃しない」形で顕在化し、勝率89%程度では気づけても原因はトレースしないと
  特定できない**。スモークは勝率だけでなく「主砲の発射回数」を見るべき
- INSIGHTS昇格候補:
  - 「軽量逆設計3個体目で手法確立: Alakazamトップ個体レプリカ(040)は自作010に74.2%、
    007に60.5%。**ladder対面表のLucario64%優位は本番トップ個体品質のAlakazamには成立しない**。
    プールのAlakazam枠は040に交代推奨（シェア1位31.6%の対面基準）」
  - 「Alakazam系レプリカの実装は攻撃コスト{P}とEnriching{C}の混同に注意（1体1枚ルールと
    複合して主砲が永久沈黙するバグの温床）」
- 派生アイデア（BACKLOG追記は親に委任）:
  - **036/038の対040再評価**: 現行主力の対Alakazam成績を040基準で測り直す（007は39.5%と判明済み。
    038 vs 040 = 61%は本実験で測定済みだが、038側の対Kangaskhanに続く要監視対面になるか）
  - **040の対Dragapult対策**(42.0%が最弱): Battle Cageはワザの直接ダメージを防がないため
    Phantom Dive系に構造弱点の可能性。ladder表のAlakazam vs Dragapult対面値と照合してから
  - 6a0dd41a46（capbloo個体、ミラー70.4%/対Starmie75%だが対Marnie34.8%）は
    メタがStarmie/ミラーに寄った場合の代替レシピ候補
