# EXP-105: 打点0の攻撃を禁止（110）— 判別不能。事実が正しくても行動が正しいとは限らない

- 日付: 2026-08-03〜04
- ベース: 104_alakazam_feat4（方策・特徴器そのまま。main.py にルールを1つ足しただけ）

## 動機（実測）

104 は `my_dmg_nullified`（打点が無効化されているか）を特徴として持っているのに、
**対Spidopsで無効化されている場面でも打点がある場面と同じ頻度で攻撃していた**。

```
対Spidops  打点あり        23/107 = 21.5% で攻撃
           無効化されている 169/774 = 21.8% で攻撃   ← まったく区別していない
```

攻撃機会の88%が無効化された状態（Articuno Repelling Veil）。打点0の攻撃は
ターンを渡すだけの完全な無駄手。**教師 Yushin 自身が同じ場面で攻撃している**
（対Spidops 17.9%）ため、その特徴を使う根拠が教師データに無く、モデルは正しく
「役に立たない特徴」と学習していた。

禁止したときの次善手: `retreat` 16.1% / カードを使う等 48.3% / `END` 35.6%
＝**約64%で1手多く行動できる**。

> **【EXP-106 による訂正】** 本レポートの対面別の数値は `run_pool` が非対応（unpaired）
> だった時期のもので、**±2.7pt のノイズを含む**。CRNで測り直した確定値は EXP-106 を参照:
> 110/111 と 104 の差は **加重 +0.35pt**、実質は **対Spidops +3.5pt（McNemar p=0.011）のみ**。
> 下記の「Kangaskhan −9.0pt」「Garchomp −7.8pt」は**どちらもノイズ**だった。

## 結果: **判別不能**

| 指標 | 110 | 104 |
|---|---|---|
| **直接対戦（n=1200・CRN）** | **48.5%** [45.7-51.3] | — |
| プールv5（n=400） | 57.96% [55.2-60.7] | 56.30% [53.6-59.0] |

n=400 の予備測定では 51.7% / 60.50% と良く見えたが、**n=1200 で 48.5% に落ちた**（上振れ）。

### 対面別（各400戦。有意差は2つだけ）

| 対面 | w | 110 | 104 | 差 | |
|---|---|---|---|---|---|
| Marnie | 53.9 | 48.8% | 45.0% | +3.7 | — |
| **Spidops** | 9.6 | **11.0%** | 6.5% | **+4.5** | ✅有意 |

```
Spidops   +4.5pt × 0.096 = +0.43pt
Garchomp  −7.8pt × 0.050 = −0.39pt   → ほぼ相殺
```

n=200 で見えた Kangaskhan −9.0pt は n=400 で −2.0pt に縮み**ノイズだった**。
代わりに Garchomp で有意な劣化。Garchomp は Rock Fighting Energy（闘ポケモン限定の
効果無効化）を積んでおり、そこで攻撃を止めたのが裏目に出ている。

## 教訓

**検証可能な事実に基づくルールでも、その事実に基づく行動が正しいとは限らない。**

```
打点0であることは事実（打点計算の真値一致99.0%・KO判定100%）
しかし「打点0なら攻撃しない」が最善とは限らない
  → 攻撃はターンを終わらせる。次善手（retreat 16%等）が悪手になる対面がある
```

EXP-103 の lethal層（詰みを100%取っても効果なし）と同じ構図。
**「正しい判定」と「正しい行動」の間にはギャップがある。**

## 実装（残す）

`agents/110_alakazam_noatk0/main.py`。環境変数 `NOATK0=off` で無効化してアンカー測定できる。
条件は `my_dmg_nullified > 0` または（`my_best_dmg == 0` かつ `my_var_atk == 0`）。
最後の条件は Dunsparce の `Trading Places`（打点0だが自分のベンチと入れ替える有用技）を
止めないため（対Marnieで実測8件）。
