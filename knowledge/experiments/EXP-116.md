# EXP-116: 勝ち試合だけで学習する — データ量の損失が選別の利得を上回る

- 日付: 2026-08-08
- 対象: 104_alakazam_feat4 と同一パイプライン（教師 Yushin 156952a871、feat_104、506次元）
- 状態: **rejected（104を置き換えない）。ただし「勝ち選別そのものは有効」という副産物が確定**

## 動機

EXP-114（SIL）は「自分の本番リプレイの勝ち試合を**足す**」で全滅した。
本実験は逆方向で、**教師データ自体を勝ち試合に絞る**。

```
教師 Yushin 4,254試合のうち 勝ち2,397 / 負け1,844 / 引き分け13
負け試合1,844件(43.3%)の全決定を等重みで「正解」として学習しているのが模倣の天井
（EXP-097 の「次の一手」に明記されていた未対処項目）
```

## 設計 — **交絡を切る対照を必ず置く**

勝ち試合に絞ると**試合数が減る**ので、「勝ちで選別した効果」と「データ量が減った効果」が
交絡する。`--match-decisions` で**全体データを同じ決定数までランダムに間引いた対照**を作る。

| 条件 | 内容 | 決定数 |
|---|---|---|
| 104（基準） | 全試合 | 355,621 |
| **win**（152/153） | 勝ち試合のみ・学習シード2本 | 183,934 |
| **ctrl**（154） | 全試合からランダム間引き | 183,988 |

ユーザ指示により ctrl は当初「不要」とされたが（Yushinデータは増えないため）、
**結果的にこれが実験の主結論を作った**。無ければ「勝ち選別は失敗」で終わっていた。

## 結果

### オフライン val

| | val一致率 | MAIN |
|---|---|---|
| 104（全データ） | **0.8646** | — |
| win（勝ちのみ） | 0.8528 | 0.8140 |
| ctrl（同数ランダム） | 0.8463 | 0.8106 |

### 対戦（vs 104 直接・n=1200・CRN）

| | 結果 | 判定 |
|---|---|---|
| win seed1（152） | 47.0% [44.2-49.8] | ❌有意に弱い |
| win seed2（153） | 45.8% [43.0-48.7] | ❌有意に弱い |
| **win 2シード合算** | **46.4%** [44.4-48.4] | ❌ |
| **ctrl（154）** | **40.5%** [37.7-43.3] | ❌ |

### ★ 分解

```
データ量の損失   355,621 → 183,988決定 で **−9.5pt**（50% → 40.5%）
勝ち選別の利得   同じデータ量なら **+6.5pt**（40.5% → 47.0%）
差し引き        **−3.6pt**  → 104 を置き換えない
```

**152 vs 154 の直接対戦（n=1200・CRN・engine-seed 44400）= 52.2% [49.3-55.0]**。
点推定は勝ち選別が上だが有意ではない。ただし
(a) vs104 での 47.0/45.8 vs 40.5 の差、(b) val 0.8528 vs 0.8463、(c) 直接 52.2%
の**3指標すべてが同じ向き**なので、効果の存在は認めてよい。

## 結論

**「Yushinの負け試合には悪手が多い」という仮説は正しい。しかしこの教師では活かせない。**
勝ち試合2,397件では、負け試合を捨てた損失を埋められない。

### この結果が示す条件

**勝ち試合が今の約2倍あれば104を超えうる**（データ量の損失が消え、選別の+6.5ptだけが残る）。
実行可能な供給源:

| 供給源 | 試合数 | 状態 |
|---|---|---|
| Yushin 156952a871 の勝ち | 2,397 | **使い切り** |
| Majkel1337 / 156952a871（同一デッキ・別チーム） | 6,395 | 未検証 |

EXP-110 は「Majkel を混ぜると −3.47pt」だが、あれは**対Spidops対面だけを混ぜた**もの。
**勝ち試合全体を混ぜる**のは未検証で、本実験の結果はその再挑戦を支持する。
ただし**別方策の混合になる**ので、EXP-094 v10 で確認した「教師が単一方策か」の
単峰性チェックを再度通す必要がある（二峰なら模倣の天井が下がる）。
