# EXP-028: Maximum Belt(1158)を007に投入（ACE SPEC交換: Hero's Cape→Belt）

- 日付: 2026-07-08
- BACKLOG: I-057
- エージェント: `agents/028_lucario_maxbelt/`
- 状態: rejected

## 仮説

Maximum Belt（どうぐ・ACE SPEC・相手**バトル場**のex/megaExへのワザダメージ+50、弱点計算**前**）を
Mega Lucario exに付ければ、Mega Brave 270→320で Marnie's Grimmsnarl ex(HP320・メタシェア1位) と
Dragapult ex(HP320) をOHKOでき、狙い対面が改善する。

## 方法

- デッキ: 007のdeck.csvの既存ACE SPEC = Hero's Cape(1159)をMaximum Belt(1158)と1:1交換
  （ACE SPECは1枚制限のため共存不可。ポケモン枠は不変）
- 方策: 007ベース、EXP-019のPPPパターンを踏襲（**KO判定のみ変更、通常のターゲット採点は不変**）
  - `_plan_attack`: 攻撃者のtoolsにBeltがあり対象がex/megaExなら `ko_damage += 50`
    （闘弱点なら+100。エンジン実装 SetProperty.h CalcDamage で+50は弱点×2の**前**に加算されることを
    ソースで確認済み。対象がベンチでもガストプランでアクティブに来るので適用可）
  - `_score_attach`: BeltをHero's Capeと同じ優先度帯（7000+）で添付、Mega Lucario ex優先・
    Riolu次点（どうぐは進化後も残る）、plan.attackerボーナス+50
- 機構検証: 計測ログ付きコピーで `BELT-KO-ONLY: atk=678 dmg=270 ko=320 tgt=648 hp=320` の発火を確認
  （Belt装着Mega LucarioがフルHPのGrimmsnarl exをOHKO圏と認識）。errors=0
- 対戦条件: seed 42、`uv run arena/run_match.py agents/028_lucario_maxbelt <opp> -n 400 -w 2` ×
  007/002/021/010、`uv run arena/run_pool.py agents/028_lucario_maxbelt -n 200 -w 2 --json arena/results/EXP-028.json`

## 結論

- **rejected**。(a) vs 007直接対戦48.0%は劣化なし圏内（CIが50%を含む）だが、
  (b) **狙い対面の改善なし**: Marnie 57.8% vs 基準60.0%、Dragapult 67.3% vs 基準66.0%、いずれもCI内で同等
- プールweightedは57.6%と007の62.3%から名目低下。主因は**対Alakazamの退行**
  （プール200戦37.0% + 追加400戦42.0% = 合算600戦40.3%、基準46.5%。z≈1.5で単独有意には届かないが一貫して負方向）
- 機序解釈: OHKO+50が価値を生む窓は「Belt(1枚)を攻撃者に装着済み ∧ 相手アクティブがフルHP320のex」と
  狭く、実戦ではチップダメージ後(270で足りる)やBelt未着手の局面が大半。一方失った
  Hero's Cape(+100HP常時)は防御的に毎ゲーム効いており、特にダメカンばら撒きのAlakazam対面で
  生存ターン数を直接削った。**条件付き攻撃+50 < 常時防御+100HP のトレードで純減**
- 補足: ミラーではBeltは無効に近い（Mega Lucario ex HP340 > 270+50=320でOHKO不成立）
- INSIGHTS昇格候補: ACE SPEC枠の交換は「差し替え先の常時価値」との差分で評価が決まる。
  Hero's Capeの常時+100HPは条件付きOHKOテック(Maximum Belt)より広く効く（EXP-019のPPP・
  EXP-028のBeltと、OHKO閾値系テック2連敗）
- 派生アイデア（親がBACKLOG追記判断）: Beltを**Capeと交換せず**トレーナー枠（Poké Pad等）と
  交換する案は本実験では未検証だが、ACE SPEC 1枚制限のため不可能。OHKO系はデッキ全体の
  打点設計（Premium Power Proの枚数等）とセットでないと単品テックでは届かない
