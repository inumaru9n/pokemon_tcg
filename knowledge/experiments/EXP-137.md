# EXP-137 / EXP-138: 教師の明確な欠陥手を消す — 重みでもルールでも効かない

- 日付: 2026-08-15〜16
- 対象: 教師が**無効化された状態で攻撃している**局面を、(137) 損失重み dw=0 で外す /
  (138) 推論時のルールで潰す
- 状態: **両方とも棄却**。137 は **−0.25pt**、138 は **−0.46pt**

## 1. ★ 教師の欠陥は実在した

DeNA の記事（HandyRL / 麻雀）にある「不自然なカード使用に**損失ペナルティ**を与える」
（負の報酬ではない。負報酬だとカード自体を避けるようになる）を参考に、
**我々の教師（Yushin）に同型の欠陥があるか**を探した。

`my_dmg_nullified` = Alakazam の Powerful Hand は**ダメカン配置＝効果**なので、
Articuno Repelling Veil や Mist / Rock Fighting Energy で**完全に消える**。

```
教師はこの状態で Powerful Hand を **5,265回撃っている**（全 Powerful Hand の **21%**）
**5,265件すべてで他に手があった**（選択肢の中央値13、打つ手なしは **0件**）
Dudunsparce（Land Crush = 素のダメージなので通る）は**選択肢に一度も現れない**
```

＝ 時間稼ぎでも打つ手なしでもない、**教師の明確な機械的欠陥**。
`my_dmg_nullified` の判定精度は本番リプレイで **97%** を確認済み。

## 2. EXP-137: 損失重み dw=0 で学習から外す

該当決定の損失重みを 0 にする（勾配も評価指標も受け取らないが、
**系列の一部としてLSTMに状態を運ばせる**ため系列からは削らない）。

```
agents/231_nul_s1 / 232_nul_s2 / 233_nul_s3（L1・3シード）
プール **−0.25pt**
```

## 3. EXP-138: 推論時のルールで潰す

学習ではなく推論側で、無効化されている間は攻撃を選ばせない。

```python
if ctx_i == 0 and float(_gv.get("my_dmg_nullified", 0.0)) > 0.0:
    _atk = [i for i in range(n_real)
            if obs.select.option[i].type == _OptionType.ATTACK]
    if _atk and len(_atk) < n_real:          # 攻撃しか無いときは触らない
        for i in _atk:
            sc[i] = -1e18
```

```
agents/234_ens_nulrule
プール **−0.46pt**
```

**ルールの方が悪い。**方策を学習で歪めるより、推論で上書きする方が害が大きかった。

## 4. 機序

対Spidops（Articuno Veil の構造カウンター）**単独では +2.98pt** 出ている。
狙った対面では効いているが、**プール全体では負ける**。

```
Spidops の重み   **1.0%**
対Spidops の改善  +2.98pt  →  加重寄与 **+0.03pt**
```

一方、`my_dmg_nullified` は**他の対面でも稀に立つ**（3%精度の誤りを含む）ので、
そこで攻撃を禁止すると素直に損をする。**発火頻度 × 効果量 が、
方策全体を触る代償を上回らなかった** — EXP-132 と同じ構図。

## 5. 教訓

> **「教師の欠陥」を見つけても、直す価値があるとは限らない。**
> 欠陥の存在（5,265回・21%・他に手がある）は疑いようがないが、
> それが**重みのある対面で起きているか**は別問題だった。

> **DeNA の手法が効いたのは、彼らの欠陥が高頻度だったから。**
> 手法を移植する前に、自分のデータでの**発火頻度と重み加重の寄与**を見積もること。

なお `my_dmg_nullified` はその後 **EXP-141 の詰み層の門**として再利用した
（`ko_opp_active` は純粋な打点計算で無効化を見ていないため）。
**特徴としては正しく、使い所が違っただけ**だった。
