# EXP-141: 詰み層は勝敗を1つも動かさない（決着が早まるだけ）

- 日付: 2026-08-17
- 対象: 222（L1×3アンサンブル）に**探索を使わない確定判定の詰み層**を足した `235_ens_lethal`
- 状態: **棄却**。1200戦で進行が変わったのは8試合、**勝敗の反転は0**

## 1. 実装

`main.py` の39行だけが 222 との差分（モデル3本・特徴器・デッキ・nn はバイト一致）。

```python
if ctx_i == 0 and _NN_ACTIVE:
    _gv = dict(zip(_keys, board))
    if (_gv["lethal_for_me"] > 0 and _gv["ko_opp_active"] > 0
            and _gv["my_dmg_nullified"] <= 0            # ← 無効化されていたら撃たない
            and _sel.minCount <= 1 <= (_sel.maxCount or 1)):
        _atk = [i for i in range(n_real) if _sel.option[i].type == ATTACK]
        if _atk:
            return [max(_atk, key=lambda i: sc[i])]     # NNの点数を無視して攻撃
```

**`search_begin` を使わない**ので、本番で探索が動くかどうか（CLAUDE.md の未確認事項）に依存しない。
`my_dmg_nullified` の門は EXP-138 の知見（教師は無効化状態で Powerful Hand を5,265回撃っていた）による。

層の実装後、同じ検証を通すと**見逃しは 31件 → 0件**（`my_dmg_nullified` の門で止まったものは無し）
＝ **層は完全に発火している**。

## 3. ★ 判定: 対照付きの自己対戦

発火が 0.075回/試合なので、素の勝率差（n=1200 で CI ±2.8pt）では原理的に検出できない。
**235 と 222 は詰み層以外が完全に同一**なので、同一 `--engine-seed` なら
**層が発火しなかった試合は完全に同じ進行になる**ことを利用する。


## 4. 教訓

> **「発火頻度 × 効果量」の見積もりは、実装前と実装後で一致した。**
> EXP-132 で「先に見積もるべきだった」と書いた手順が、今回は正しく機能した。

また **稀にしか発火しない変更の測り方**として、
「**ベースと差分のペアを同一シードで走らせ、進行が食い違った試合だけを取り出す**」
が有効だった。集計値（0.5175 vs 0.5175）は完全に一致しており、
**素の勝率比較なら「差がない」としか言えなかった**ところを、
「8試合が変化し、その全てが手数短縮のみ」まで特定できた。

EXP-053 が「探索族で唯一生き残ったのは lethal-only」と結論していたが、
それは**探索を持たない条件文ベースの方策**での話。
**NN方策は `lethal_for_me` を特徴として持っており、既にほぼ自力で詰みを取っている**。
（見逃しは0.075回/試合、しかもその局面はどのみち勝っている）
