# EXP-125: 決定化ロールアウトは、隠れ情報を推測した瞬間に価値を失う【キルゲート】

- 日付: 2026-08-12
- 対象: EXP-124 が生成した4,193局面のうち M=24 の600局面
- 状態: **棄却。推論時探索としてのExItも死**

## 1. 何を測ったか

EXP-124 で「186の貪欲手を決定化ロールアウトで選んだ手に替えると **+9.45pt**」を確認したが、
その数字は `_hidden(ptr, i)` で**相手の手札・山・サイドを真値で**渡して得たものだった。
本番の推論時には推測するしかない（本番観測の `search_begin_input` の引数がすべて
"Predicted Card ID" なのはそのため）。**推測に置き換えて何割残るか**が、
ExItを推論時探索に変えられるかの唯一の分岐点だった。

## 2. 設計（選択バイアスが原理的に入らない形）

```
1. **推測した隠れ情報**でロールアウトし直して best' を選ぶ
2. その best' を、生成時に保存済みの**真値ロールアウト行列 R（候補×24）で評価**する
→ 選択（推測標本）と評価（真値標本）が独立なので、二段構えの分割すら不要
```

推測は**エージェントが正当に知っていること**だけから組む:

```
自分側  deck+prize の多重集合は既知（自分の60枚と見えている札から引ける）
        **どれがサイド6枚かは不明** → 分割をサンプル
相手側  アーキタイプが同定できれば残りの多重集合が引ける
        **手札／山／サイドの分け方は不明** → 3分割をサンプル
```

これは**相手のリスト読みが完璧な場合の上限**である。実装ではアーキタイプ同定の誤りが
上乗せされるので、実測値がこれより良くなることはない。

**対照を2本置いた**（同一600局面・同一評価。対応ありで比較する）:
- 真値(独立24本) = 予算そのものの選択精度。「24本では元々この程度」を切り分ける
- 真値(前半12本) = EXP-124 で使った二段構え推定との接続

`search_begin` は `lib.AgentStart()` の独立ポインタと `observation.search_begin_input` だけを
使うので、**保存済み局面から再実行できる**（＝推論時にも同じ形で動くことの確認も兼ねる）。

## 3. ★ 結果

```
同一600局面 / 後半12本で評価
選び方                gap/局面          95%CI          真値bestとの一致
真値(独立24本)        **+2.95pt**   [+1.67, +4.23]        52.5%
真値(前半12本)          +2.45pt     [+1.15, +3.75]        79.7% ※Rと標本を共有
推測(24本)            **+0.07pt**   [−1.19, +1.33]        43.0%
（でたらめに選ぶ）                                          36.1%

**推測 − 真値（対応差） −2.88pt ±1.12   z=−5.05**
```

事前登録した合否（真値 +3.14pt 基準で「>= +1.57pt なら建造 / < +0.79pt なら死」）に対し、
実測 **+0.07pt** ＝ **棄却**。

**真値なら独立な24本で +2.95pt が取れる**ので、落ちた原因は**探索の本数ではなく推測**である
（対応差 z=−5.05）。

### 拾えているのは賭け金の小さい局面だけ

一致率は 乱択36.1% < **推測43.0%** < 真値52.5% で、乱択超えの信号の
**(43.0−36.1)/(52.5−36.1) = 42%** は拾っている。にもかかわらず gap は
**0.07/2.95 = 2%** しか取れていない。**当てられるのは差の小さい局面ばかり**という構図。

## 4. ★ 機序と、殺した範囲の境界

ロールアウトは**終局まで打つ**ので、相手の手札7枚が次ターン何をするかに全面的に依存する。
多重集合が正しくても割り当てが違えば別のゲームになる。24サンプルの平均を取っても
ランキングが復元されない＝**分散でなくバイアス**。

> **この結果が殺したのは「終局までの決定化ロールアウト」であって、探索一般ではない。**
> **浅い探索は隠れ情報にほとんど依存しない**。EXP-053 で探索族の唯一の生き残りが
> lethal-only だったのは偶然ではなく、「今このターンで倒し切れるか」は相手の手札を
> 知らなくても**確定判定できる**からである。

したがって EXP-124 で測った **+9.45pt の余地は、相手の手札を知らないと取れない部分と
隠れ情報非依存の部分に分かれ、我々が取れるのは後者だけ**。186 は lethal 層を持っていない
（`agents/084_alakazam_majkel/main.py::_lethal_search` に実装がある）。

## 5. 計画への影響

`knowledge/`（I-109 Phase RL 計画）の後段「価値誘導探索」は
**1〜2ply展開して葉をVで評価**する設計だった。展開に `search_begin` を使う点は同じだが、
**終局まで打たない**ので本実験の結論はそのままは当てはまらない。
ただし「相手が次に何をするか」を1ply読む時点で相手の手札に依存するため、
**同じ検定を通してから着工すること**（本実験の枠組みをそのまま使える。
`selfplay/exit_belief.py` の `roll_from` を「N手で打ち切ってVを返す」に差し替えるだけ）。
