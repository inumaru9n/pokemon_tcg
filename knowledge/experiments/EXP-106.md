# EXP-106: run_pool が非対応（unpaired）だった — 本日の比較は全て ±2.7pt の定規で測っていた

- 日付: 2026-08-04
- 対象: `arena/run_pool.py`（測定装置そのもの）

## 発見の経緯

EXP-105（110＝打点0の攻撃を禁止）の追試で、プールが**対Marnie +7.2pt（z>2で「有意」）**を出した。
しかし機序を追うと、対Marnieでは無効化が一度も起きず（475件中0件）、**ルールは1度も発火しない**。
発火しないなら 110/111 と 104 は同一の手を打つはずで、差はゼロでなければならない。

同一CRN（`run_match --engine-seed 31337`）で確認:

```
111 vs 101_marnie_luca   199/400
110 vs 101_marnie_luca   199/400     ← 完全一致。3体は同一の手を打っている
104 vs 101_marnie_luca   199/400
```

**機序上ゼロの差が、プールでは +7.2pt・z>2 の「有意差」として現れていた。**

## 原因

`run_pool.py` は `run_match.run_series` を**第6引数まで**しか渡しておらず、
第7引数 `engine_seed_base`（CRN機構、`run_match.py:100 derive_engine_seed`）が常に `None` だった。
つまり**プール評価は毎回エンジンのシャッフルが変わる独立標本**で、
候補どうしの比較が対になっていなかった。

## 修正

`--engine-seed` を追加し `run_series` に渡す。**候補比較では必ず同じ値を指定する。**

```bash
uv run arena/run_pool.py agents/NNN_xxx -n 400 --engine-seed 20260804 --json out.json
```

## EXP-105 の訂正

EXP-105 は「110 の Garchomp −7.8pt は Rock Fighting Energy 下での誤爆が機序」と結論したが、
**CRNで測ると 110 と 111 は Garchomp 400戦中397戦が同一結果で差は −0.2pt**。
誤爆自体は実在した（対Spidops 15% / Garchomp・Kangaskhan 4%。`my_dmg_nullified` は
「ダメカン技が消されるか」の判定なので、Kadabra の Super Psy Bolt 30 のような
**実ダメージ技まで止めていた**）が、**勝敗はほとんど動かしていない**。
−7.8pt も、その前の Kangaskhan −9.0pt と同じくノイズだった。

## 本当の教訓

**本日の実験9件は全て ±2.7〜2.8pt の定規で測っていた。**

| 実験 | 当時の判定 | 定規 |
|---|---|---|
| EXP-098〜101（階層・特徴・AWR） | 「差なし」 | プール非対応 ±2.7pt |
| EXP-103（lethal層） | 「効果なし」50.0% n=600 | H2H ±4.0pt |
| EXP-105（打点0禁止） | 「判別不能」48.5% n=1200 | H2H ±2.8pt |

**「有意差なし」の一部は「改善が無かった」ではなく「見えなかった」可能性がある。**
実際、111 の真の効果 +0.35pt は、従来の定規では絶対に検出できない大きさだった。

ただし注意: **この7.7倍は「ほぼ同一のエージェント同士」だから得られた**（400戦中399戦が同一結果）。
モデルの重みが違う候補どうしでは初手から分岐するため、CRNが揃えるのは配札だけで、
分散削減はもっと穏やかになる。**ルール上乗せ型の比較には劇的に効く**。
