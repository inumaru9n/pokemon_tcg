## 手法

058の学習設定（lr=0.05、rounds固定、4日分）を見直し:
- **lr=0.01**、rounds は early stopping（patience 150、最大8000）で自動決定
- **3分割**（early stoppingと選定を別データにする）:
  - train = 07-09..13（96,023決定、木の成長）
  - valid = 07-14（24,085、early stopping判定のみ）
  - test = 07-15（24,559、グリッド選定+報告）
- グリッド: num_leaves ∈ {31,63,127} × min_data_in_leaf ∈ {30,50,100}

**3分割にした理由**: 当初valid1本でearly stopping判定とグリッド選定を兼ねており、
これは選定側のwinner's curse（CLAUDE.md統計基準の既知の罠）。ユーザ指摘で分離。

### ⚠️ 訂正1（2026-07-20、ユーザ指摘）: 割り当てを間違えている

正しくは **val = early stopping + グリッド選定 / test = 報告のみ**。本EXPは
**選定をtestで行い、同じtestで報告している**ため、報告値0.7767は選定バイアスを含む。
「分ける」ところまでは正しかったが、分けた先が逆だった。

グリッド表から補正できる（再学習不要）: **validで選ぶと 31/50（valid 0.7858）が選ばれ、
その test は 0.7754**。報告値0.7767との差 = **0.13pt が選定バイアスの実害**。

- 一致率の正しい値は **0.7754**（0.7767ではない）
- **アリーナ vs058 53.17% は無傷**（独立測定なので選定バイアスと無関係）
- ただし**出荷した `model_070.npz` は 31/100**＝testで選んだ構成。実害0.13ptだが記録として残す

### ⚠️ 訂正4（2026-07-20、最重要）: 「validated」は偽陽性の可能性が高い

EXP-073で全ペア・全プールを揃えた結果、**058 ≈ 073 ≈ 074 ≈ 070 が一切区別できない**:

| 比較 | スコア率 | CI |
|---|---|---|
| 073 vs 058（データ効果） | 0.4931 | [0.458, 0.528] |
| 073 vs 074（ハイパラ効果） | 0.5019 | [0.467, 0.537] |
| 074 vs 070（選定バイアス） | 0.4937 | [0.459, 0.529] |
| プール（058/073/074/070） | 0.758 / 0.744 / 0.749 / 0.747 | 全てCI重複 |

これらが全て中立なら **070 vs 058 も50%のはず**だが、実測は 0.5317 [0.5070, 0.5562]。
CI下限50.70はギリギリで、**本セッションで多数の比較を行っている以上、多重比較で
1つ閾値を越えるのは十分あり得る**。最も妥当な読みは「**070の改善は実在しなかった**」。

**教訓: CI下限がギリギリ50%を超えただけの結果を単発で「validated」としてはいけない。
分解実験（要因ごとの単独測定）を伴わない改善主張は、多重比較の中で偽陽性を拾う。**

### ⚠️ 訂正2（2026-07-20）: 058の学習設定の記述が誤り

「058は rounds固定」は誤り。**058も early stopping を使っていた**（patience=80、best_iter=121）。

### ⚠️ 訂正3（2026-07-20）: 交絡が未分離だった

070は058から**データとハイパラを同時に**変えており、vs058 +3.2ptの出どころを分離していない。

「モデルチューニングは交絡なしに効く経路」という本EXPの結論3は、**別の交絡を残したまま

## 結論

**validated（小改善）。ただし効果量は小さく、コストは5倍。**

1. **モデルチューニングは交絡なしに効く経路**（EXP-069のルール矯正と対照的）。
   一致率 +5.1pt(test) → vs058 +3.2pt。**手書きルールで6連敗した領域が、モデル側では素直に動く**
2. **プールは横ばい、vs058は勝ち**という非推移。「一致率⊥アリーナ寄与」（EXP-052/056/060/070）の
   再確認だが、今回は一致率の増分が大きかったため直接対戦には現れた
3. **lr=0.01のコスト**: 木が10倍・サイズ5倍・推論81ms。600s/game予算内なので本番可用だが、
   これ以上の低lrは割に合わない
4. **3分割の教訓**: early stoppingと選定を同じデータでやるのはwinner's curse。
   以後の学習系はtrain/valid/testを分ける（本EXPで運用確立）
