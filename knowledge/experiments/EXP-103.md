# EXP-103/104: lethal層 と 価値誘導探索 — どちらも効果なし。V の分解能の限界

- 日付: 2026-08-03
- ベース: 104_alakazam_feat4（プールv5 59.21%、提出済み sub 55202682）

## EXP-103: lethal層（詰みの取り逃し防止）

### 動機

`tools/lethal_diag.py` の実測で、104 は**そのターンで勝てる詰みを27.4%見逃していた**
（62回中17回）。EXP-099 で打点計算を直した結果 **KO判定の真値一致が100%**になったので、
`search_begin` を使わずに確定判定できる。EXP-053 の結論
「探索ファミリーで生き残ったのは lethal-only（確定検証×高頻度×効果確定）のみ」とも整合する。

### 結果: **効果なし**

| 指標 | 108（lethal層） | 104 |
|---|---|---|
| 詰みの取得率 | **100.0%**（0件見逃し） | 72.6% |
| **vs 104 直接対戦** | **50.0%** [46.0-54.0] n=600 | — |
| プールv5 | 57.52% | 59.21% |

`KOのみ`（勝ちには足りないKO）の挙動は218/969で完全に不変＝**詰み以外には触っていない**。

### 解釈

見逃していた詰みは**取り逃しても負けに直結していなかった**。詰み局面は1試合0.6回で、
見逃しても次のターンで勝てることが多い。**頻度が低すぎて勝率に出ない。**

## EXP-104: 価値誘導探索

### 設計

方策の上位k候補を `search_step` で展開し、葉を value head（104の方策を凍結して
v_head だけ学習、per-decision AUC 0.807）で評価して並べ替える。
`min_margin` を単一のつまみにして「Vをどれだけ信じるか」を単調に振る。

### 潰した実装バグ3件（いずれも例外を出さずに静かに壊れる型）

| # | バグ | 症状 |
|---|---|---|
| 1 | `from cg.api import search_begin` の置換失敗 | `NameError` が `except` に吸われ、**探索が35/35回とも無効**。min_marginを4水準振っても結果が1勝も動かなかった |
| 2 | 葉が相手視点で**自分の手札が None** | `hand_*` 22次元と `left_*` 22次元が全ゼロ＝「手札を持たない自分」を評価していた |
| 3 | ターンを打ち切る設計 | 葉が学習データに**1件も無い**状態（ターン終了直後）になっていた |

3の修正として「1手だけ進める」形に変更。実測で**89.3%は自分の手番のまま**で特徴が完全に作れる
（ATTACK ですら24/27件。サイドを取る TO_HAND が挟まるため）。MAIN の END のみ除外。

### 結果: **単調に悪化。min_margin=0 で 300戦0勝**

| min_margin | MAINのみ | 全ctx | （参考）ターン打ち切り版 |
|---|---|---|---|
| ∞（探索オフ） | 50.0% | 同左 | 50.0% |
| 0.5 | 40.0% | 40.7% | 33.0% |
| 0.2 | 15.3% | 15.3% | — |
| **0.0** | **0.0%** | 0.3% | 1.0% |

### 原因: **V の分解能が1手の寄与より粗い**

教師データ600試合・ターン内の連続決定42,361ペアで測定:

```
教師が1手打ったときの ΔV = V(s_t+1) − V(s_t)
  勝ち試合  平均 +0.0070  正の割合 52.2%
  負け試合  平均 +0.0049  正の割合 51.3%
```

**教師の良手ですら ΔV が正になるのは52.2%＝コイン投げ。** 候補間の差はさらに小さいノイズ。
それで方策（MAIN一致率0.833）を上書きすれば、情報を捨てて乱数で選ぶのと同じになる。

一方で **V の品質自体は良好**（検証用300試合、学習に使っていない試合）:

| 指標 | 試合単位AUC |
|---|---|
| **学習した V** | **0.9442** |
| 自明: サイド差 | 0.8896 |
| 自明: 残りサイド | 0.8198 |
| 序盤(前30%)のみ | V=0.790 vs サイド差=0.580（**+21pt**） |

序盤でサイド差を21pt上回る＝自明な指標の焼き直しではない。
**「試合の勝ち筋は読めるが、1手の寄与は読めない」**という状態。

### なぜ学習し直しでは直らないか

ΔV の情報量が無いのは**ラベルが試合の勝敗（数十手先）**だから。同じ試合の全決定が
同じラベルを共有するので、1手の寄与は粗い信号に埋もれる。**入力を step 後の盤面に
合わせても、ラベルが同じなら分解能は上がらない。**
局所の分解能には反実仮想（同じ盤面から複数の手を試したデータ）が要り、
それは自己対戦の領域＝EXP-096 で60,000試合回して無変化だった場所。
