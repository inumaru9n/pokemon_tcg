# EXP-107: デッキ構築（60枚）— 方策を凍結したまま初めて104に有意勝ち越し

- 日付: 2026-08-04
- ベース: 104_alakazam_feat4（方策・特徴器・重みは**完全に凍結**。deck.csv の枚数だけを変えた）

## 動機

方策側は9連敗（EXP-098〜105）。一方 **60枚は一度も触っていなかった**。
EXP-106 で「Alakazam の対Spidops 21.3%（ladder n=2676）はアーキタイプの性質で方策では直せない」
と確定したため、残る梃子は構築だけになった。

**3つの独立なソースが同じ変更を指していた**:
1. ladder実測: 構築 `8c7d3f998f`（Dudunsparce 3）は**対Spidops 50.0%**、我々の `156952a871`（同2）は30.3%
2. 公開notebook `A Better Hand — Alakazam Rising Tide v21`（jazivxt・38票）は Dudunsparce **4**
3. 機序: Alakazam の唯一の攻撃 Powerful Hand は**ダメカン配置＝効果**で Articuno の
   Repelling Veil に消えるが、Dudunsparce の Land Crush 90 は**ダメージ**なので通る
   （104は対Spidops の攻撃機会1026回で**一度もDudunsparceを前に出していない**）

## 実装上の注意（次元が黙って壊れる）

`DECK_COUNTS` は deck.csv から読むので、**枚数0になったカードの `pool_`/`left_` キーが消えて
特徴次元が縮み、104の重みが別の特徴に掛かる**（例外は出ない）。
104のキー集合を保ったまま枚数だけ差し替え、**実盤面で FEAT_KEYS の完全一致（506次元）を検証**した。

## ★ Neutralization Zone の分離実験（112 − 113 ＝ ACE SPEC 1枚だけ）

```
Enriching Energy   = 貼ったとき4枚ドロー（安定性）
Neutralization Zone = 相手の ex/V の攻撃から、**ルールボックスを持たないポケモンへの全ダメージを防ぐ**
```

**104の盤面は Abra/Kadabra/Alakazam/Dunsparce/Dudunsparce/Shaymin ＝6種すべて非ルールボックス**
（exは Fezandipiti ex 1枚のみ）。一方**プール8デッキの主戦力は全てex**
（Grimmsnarl ex / Mewtwo ex / Kangaskhan ex / Garchomp ex / Dragapult ex / Lopunny ex …）。
我々の攻撃役は全て非exなので**こちらの打点は止まらない＝一方的**。

| 対面 | w | 差 | 加重寄与 |
|---|---|---|---|
| **Spidops** | 9.6 | **+27.0** | **+2.59** |
| Marnie | 53.9 | −5.8 | −3.10 |
| Garchomp | 5.0 | −9.0 | −0.45 |
| Dragapult | 2.5 | −15.5 | −0.39 |
| その他 | | | −0.33 |
| **合計** | | | **−1.68pt** |

**現行メタでは Enriching Energy の方が正しい**（4枚ドローの安定性が全対面に効く）。
ただし利得はSpidopsに集中しているので、**損益分岐が計算できる**:

> **Spidops のシェアが 15.8% を超えたら Neutralization Zone に入れ替える**（現在 9.6%）

締切直前のデッキ確定を、感覚でなく1つの数字で決められる形になった。

## 教訓

**「デッキ修理は方策を変えずに最大の利得を出す」は他チームも独立に報告している**
（discussions/724187: 0.6%→9.2%、方策不変）。我々は9回方策を磨いて全て失敗し、
**60枚を1回触っただけで初めて有意差が出た**。

注意: CRNの分散削減は**ほぼ同一のエージェント同士でしか劇的に効かない**（EXP-106）。
デッキが違うと初手から分岐するので、プール加重差のCIは ±0.35pt ではなく **±3.5pt** に戻る。
113の「プール +1.51pt」は有意でなく、**有意なのは直接対戦の 55.2% の方**。

## ★ 同じ罠を直後に自分で踏んだ（記録）
