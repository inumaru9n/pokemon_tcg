# EXP-136: 確率平均アンサンブル — 容量が適正なら効く（現行提出物 222 の根拠）

- 日付: 2026-08-15
- 対象: L1（1層LSTM・正規化なし）の複数シードを**確率平均**で合流
- 状態: **採用**。プール **71.45% → 72.51%（+1.06pt）**。`agents/222_L1n_ens` として提出

## 1. 経緯 — 一度棄却した手を、条件を変えて再試行した

**EXP-117 はアンサンブルを棄却していた**（val +0.86pt → プール ±0.00pt）。
ただしそれは **L2（=186の構成、1,315,331パラメータ）** で測ったもの。

EXP-134 で **容量が飽和ではなく過剰**と分かった（val は深さに単調 L1>L2>L3>L4）。
**容量が適正なら、シード間の誤差が独立に近づいてアンサンブルが効くのではないか**、が仮説。

## 2. ★ 3本は本当に別の解にいる

```
L1 3シードの重みの cos類似度   **0.033**（ほぼ直交）
**重み平均（model soup）は完全に壊れる**   val 0.8759 → **0.5326**（agents/221_L1n_soup）
```

同一データ・同一ハイパラでシードだけ変えた3本が、**重み空間では無関係な場所にいる**。
だから重みを混ぜてはいけないが、**出力を混ぜるなら独立性が利益になる**。

## 3. ★ スコア平均ではなく確率平均

```python
score_i = **log( mean_m softmax(s^m)_i )**
```

生スコアを平均してはいけない。`ctx_scale` / `ctx_bias` はモデルごとに別のスケールに育つので
**s^m は単位が揃っていない**。softmax を通すと確率という共通単位になり、初めて足せる。

各メンバーは**独自のLSTM状態**を持ち、決定ごとに全員が1ステップ進む。
実際に選ばれた手（`prev`）は全員に共通で流れる＝**1本の行動軌跡を共有する方策のアンサンブル**。
状態を共有してはいけない（層の意味が個体ごとに違うため）。

## 5. ★ 本数は3で頭打ち

| N | val | プール |
|---|---|---|
| 1 | 0.8746 | 71.45% |
| 2 | 0.8835 | — |

**val は N とともに上がり続けるのに、プールは N=3 で完全に止まる。**
計算を1.7〜2倍にして +0.00pt。**「時間予算に余裕がある」ことと「使えば強くなる」ことは別**。

## 6. ★ 組み合わせの当たり外れが 1.18pt ある

**同じ6本のプールから作った N=3 の三つ組で 72.08% 〜 73.26%。**
222 の 73.26% は**上振れ**で、正直な推定値は家族平均の **72.51%**。

同様に **186 の提出重みは3シードの最良個体**（71.25 vs 平均 70.93）で、
これも上振れ。**両方を平均で見て初めて +1.58pt という利得が正しく見える**。

## 7. 教訓

> **一度棄却した手法は、棄却したときの条件が変われば再試行する価値がある。**
> EXP-117 のアンサンブル棄却は L2 での話で、L1 では +1.06pt 出た。
> 機序（シード間の直交性）まで測れば、どの条件で効くかが説明できる。

> **単一の構成の測定値を代表値として使わない。**
> 三つ組の当たり外れ 1.18pt、単体シード間 1.39pt はどちらも
> 「候補どうしの差」と同オーダー。**必ず複数シード/複数構成の平均で比較する。**
