# EXP-072: MLレイヤの前提条件分解（turn 1拡張） — 072_070_turn1

- 日付: 2026-07-19
- 動機: EXP-071の副産物で「turn 1 でMLレイヤが呼ばれていない」設計事故を発見
- エージェント: `agents/072_070_turn1/`（070のコピー。モデル・特徴量・ルール全て不変、分岐構造のみ変更）
- 状態: **neutral（性能不変）→ アーキテクチャ簡素化として採用**

## 変更内容

070まで、`agent()` の分岐は2つの関心事を1つの条件に束ねていた:

```python
if obs.select.context == SelectContext.MAIN and obs.current.turn >= 2:
    lethal → ml → lines
return policy(obs)
```

`turn >= 2` は **lethal探索の前提**（turn 2以前にKOは成立しない）であって、MLレイヤの前提ではない。
MLレイヤが後からこの分岐に相乗りしたため、turn 1 ではモデルが呼ばれず052ルールのみで判断していた。
各レイヤが自分の前提条件を持つ形に分解した（`main.py:2532-2543`）:

```python
if obs.select.context == SelectContext.MAIN:
    if obs.current.turn >= 2:      # lethalの前提のみ
        lethal...
    if _M057 is not None: ml...    # 前提なし
    if F054_LINES: lines...
return policy(obs)
```

**「設計事故」と判断した根拠**: policy側に turn 1 を特別扱いするコードは1箇所も無い
（`turn == 1` / `turn <= 1` / `turn < 2` いずれもヒット無し）。EXP-045/052のミクロ較正で
意図的に作られた挙動ではない。モデルは turn 1 のデータでも学習済み。

## 結論

**neutral。性能改善としては主張できない。**

1. **予想通りアリーナでは検出できない**。オフライン+0.5ptは788戦（CI±3.5%）では解像しない。
   真の効果が+1ptでも約10,000戦必要だが、**LBのレート分散は同一エージェントで31-100pt**
   （discussion 712621）なので、+1pt未満の局所効果を確定させても提出判断は変わらない。追わない
2. **EXP-060の再確認**: 「序盤は重要だからレバレッジが高いはず」は成立しない。
   オフライン一致率の増分は、それが決定の重要度で重み付けされていない限りアリーナに転移しない
3. **採用理由は性能でなくアーキテクチャ**: 挙動が測定上同一（0.4949）なので、
   タイブレークを構造の簡潔さで決めてよい。複合条件が1つ減り、各レイヤの前提が明示される。
   turn 1でモデルが教師と96%一致する（ルールは79%）点も、
   「強い教師への忠実な模倣」というプロジェクトの設計思想と整合する

**注意**: 「ローカル中立」は「本番中立」を保証しない（EXP-042: レプリカ対戦値は本番対面表と
±14-35ptズレる対面がある）。ただし今回はモデル管轄を広げる方向＝設計思想に沿う方向の変更なので、
リスクは対称でなく我々の仮説側に有利と判断した。
