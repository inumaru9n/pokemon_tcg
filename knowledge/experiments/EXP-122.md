## 1. 語彙（META_CARDS）の設計思想を確立した

② 学習可能性  教師データでの board_mu が **0.02 以上**                  → 12枚を足切り
             ＝ **69枚**
```

②の根拠は166の実測。**教師が観測していないカードを足すと死に次元になり、−2.29pt**。

## 2. ★「冗長だから消してよい」は誤り — 重複列は実効学習率の倍率

171で「`my_act_prize` は `ms0_prz` と同一だから冗長」として4特徴を削除したが、
**重複列は無ではない**ことを重みの構造から実証した。

```
仮説: 完全に同じ入力列は毎ステップ同一の勾配を受ける → w = init + Δ（Δ共通）
      → 2列の差は**初期化の差だけ**残るはず。予測 ‖wa−wb‖ ≈ 0.522

ペア                          ‖wa‖   ‖wb‖  ‖wa−wb‖   予測    合成
opp_act_prize / os0_prz      1.263  1.282   **0.549**  0.522  2.485
my_act_prize  / ms0_prz      0.865  0.874   **0.538**  0.522  1.653
対照: 無関係な生きた列ペア                 **1.397**（2.5倍）
```

**予測とほぼ完全に一致。** つまり重複列は「その方向の学習成分を2倍にする」装置として働く
（1列なら init+Δ、2列なら init+init+**2Δ**）。早期終了を使う以上、実効学習率2倍は解を変える。

**帰結**: 104の特徴器は最初から**約50組の重複**を含んでおり（`left_*`/`pool_*` がデッキ22枚ぶん、
`act_*`/`ms0_*` がアクティブ属性ほぼ全部、`opp_act_prize`/`os0_prz`/`prz_if_opp_act_ko` は×3で
合成‖w‖3.690＝中央比3.84の最大強調）、その状態で104/117が最良成績を出している。
**「掃除」は動いている強調構造への無統制な変更である。**

## 3. clip は定数列の対症療法にすぎなかった

EXP-111 は「新語彙 × 旧教師データ」で sd が下限(1e-3)に張り付いた列が本番で744σを噴く
事故を、±10σクリップで塞いだ。本実験でその前提が消えていることを確認した。

```
170の定数列21個の内訳（104と完全に同一）
   状態異常8 / どうぐ8 / 行動不能2 / 抵抗力3   ← **opp_seen は1つも無い**
   ＝ ②（教師観測≥0.02）が語彙側の穴を根治済み

実対戦での |z| の桁（生きた503次元のみ）
   中央値 8.3σ / 95% 14.9σ / **最大 34.3σ**   |z|>10 は33.0%の決定
   定数列は発火すれば **1,000σ級**

→ 2つの問題は桁が2つ違う。clip 10σ は後者を止められる代わりに
  **正当な稀事象を含む33%の決定に掛かる**
```

本番リプレイ1,130戦で定数列は **1.1%の試合**（confused 0.9% / poisoned 0.2%）で実際に発火する。
**対処は clip でなく定数列の除去**（訓練中ずっと0なので、消しても失う情報はゼロ）。

## 8. ★ 正規化の病理 — 104から全モデルにあった欠陥（180〜186）

### 発端: 語彙を広げたら −1.60pt 落ちた

180（語彙を①のみ81枚に拡大）が 174 から **−1.60pt**、対Kangaskhan **−7.9pt**。
バグを疑って全数調査したが**特徴器・モデル構造・実行時のいずれにも異常なし**
（共通440列を同一盤面で突合して不一致0、card vocab/試合/系列/n_cls も一致、
_NN_ACTIVE も59決定後にTrue、errors 0）。

原因は**標準化そのもの**だった。

```
z = (x − mu)/sd   稀なカウント特徴では sd ≈ √p なので **z(1枚) ≈ 1/√p** が発散する

180で追加した稀な語彙11枚   z(1枚) **4.6〜23.7σ**（既存69枚は中央2.3σ・最大5.2σ）
重みは中央値並み(0.79〜1.00)なので、**発火した瞬間に既存語彙の5倍の寄与**を注入
```

さらに調べると、**語彙より深刻な列が元からあった**。

```
1/sd（1単位あたりのσ）を族別に測定
   スロットの稀なフラグ  73列  中央 4.6 / **最大 199.7**（os5_resist_vs_me）
   状態異常フラグ         2列  中央 62.2 / 最大 71.6
   opp_seen              80列  中央 2.7 / 最大 23.7
   ─────────────────────────────
   pool_/left_（自山）    22列  中央 1.0 / **最大 2.0** ← 健全
   n_/line_（場の体数）   16列  中央 1.0 / 最大 2.7  ← 健全
```

**ベンチ後方スロットが埋まること自体が稀**なので `os5_*` の sd が 0.005 まで縮み、
立った瞬間に200σを注入していた。**104から186まで全モデルに存在**。

### 修正: 有界カウントは標準化しない

```
判定は「有界か」ではなく **1/sd が大きいか**（＝ゼロに張り付く稀な事象か）
   **0/1フラグ 69列 → 標準化しない**（mu=0/sd=1。既に0〜1なので割らない）
   **opp_seen → x/4**（同名4枚まで。**ACE SPEC は x/1**）
   **noeffect_e → x/3**
   **その他302列 → 標準化のまま**（pool_/left_ は健全なので触らない）
   clip は**入れない**（原因を消せば対症療法は不要）
```

`opp_seen` に実測maxでなく**意味上の上限4**を使うのは、稀な札は実測max=1にしかならず、
実測で割ると「1枚見えた」の符号化がカード間で4倍ずれるため。
一方 `pool_/left_` は 4→3→2→1→0 と必ず全域を通るので実測max=DECK_COUNTSで一致する。

|---|---|---|
| 正規化修正の効果 | **184−180 = +0.73pt**（対Kangaskhan **+6.9pt**） | **185−174 = −0.17pt** |

**174の語彙では稀な列が少なく病理が発現していなかった**ので直す余地がなかった。

## 9. mu（観測平均）は選抜の軸として誤り

```
**mu = 正例率 × 観測時の平均枚数**

後者は「相手が何枚積んでいるか」で学習可能性と無関係。実測で 1.00〜3.47倍の幅
   Surfer     正例 3,746  mu 0.0086  観測時 **1.00枚**
   Tera Orb   正例 3,837  mu 0.0134  観測時 **1.52枚**   → 正例ほぼ同じで mu は1.56倍
   Festival Grounds 正例 **4,486** で却下 / Dipplin 正例 4,445 で採用（**逆転**）
```

閾値0.02にも根拠がなく、採用集合の最小値(0.0218)のすぐ下に手で置かれていた。
0.02付近のギャップは0.0024〜0.0026で、分布全体の最大ギャップ0.24とは桁が2つ違う。

### 代わりの基準: 正例数 >= k × d_model

1列は enc.0 で隠れ256ユニットへ繋がるので**256本の重みを推定する**。
その1本あたりの標本数で測る。**モデル容量に紐づくので恣意性が小さい**。

```
174の語彙69枚  最小 4,445正例（1本あたり **17.4**）/ 中央 21,025（82）
184で追加した12枚  **1.4〜17.5**  → 174の下限をほぼ全部下回る
k=17 なら 174 とほぼ同一集合（差1枚）、k=10 なら +5枚
```

- **1182 Boss's Orders は既存の `opp_used_boss` と定義上同一**だった

- 1137 Tool Scrapper は ARCH_DECK では4系統だが**実観測 0.6〜1.1%**。②で落ちる
- 残る3枚（Fezandipiti / Unfair Stamp / Xerosic's）も勝率への寄与は測定分解能以下

当初⑦「追跡価値=正例率>=5%」を別基準にしたが、**正例率と正例数は同一軸**（Nで割るだけ）
なので廃止した。②を k=17 にすれば⑦なしで Tool Scrapper は落ちる。

### 2×2（設計 × デッキ）で交互作用が出た

```
            104デッキ   117デッキ
104設計     70.81%      **73.03%**

## 12. データ追加（+22%）は −0.15pt

**169 = 104と特徴器・語彙が完全に同一で、データだけ +22%** という統制実験。

```
加重  104 70.81% → 169 **70.66%**（**−0.15pt**）
   得た  対Ogerpon **+6.4pt**（104の期間にOgerponがほぼ存在しない）
   失った 対Marnie −0.9 / 対Kangaskhan −3.5
```

機序は教師の劣化。**追加期間で Yushin の勝率が 56.3% → 53.0%** に落ちている。

| 相手 | 旧期間 07-17〜29 | 追加分 07-30〜08-07 |
|---|---|---|
| Marnie | 52.0%（1,886戦） | **43.9%**（367戦） |
| Alakazam | 73.8%（924戦） | **53.0%**（66戦） |
| Mega Lopunny | 68.8%（48戦） | 55.1%（198戦） |

「新しい対面を教える代わりに、既存の主要対面で教師の悪手を学ばせる」交換になっている。
なお104の期間に戻す案は、②が正しく機能する結果として
**Lively Stadium が観測0回・Mega Lopunny ex が正例2,215**となり
語彙が79→69枚に縮む＝104の盲点（Lopunny 14.3% + Ogerpon 6.0% を識別できない）が再現するので却下。
