**【2026-08-17・最重要】「醜い」と「不要」は別。負債の中に load-bearing なものが混ざっている**（[EXP-142](experiments/EXP-142.md)）: 設計上の最大の負債は **65クラスのデッキ固有表**（`CLS_PLAY`/`CLS_EVO`/`CLS_AB`/`CLS_ATK`/`ATTACH_BUCKET` を deck.csv から生成、しかも Abra(741)/Kadabra(742) を同一クラスに潰す）。これを cross-encoder（joint MLP）で置き換えると **val −0.54pt（3シードとも同符号、t=−7.8）/ MAIN −1.02pt**。cls_head を戻した `jcls` は base 並み（−0.18pt、n.s.）なので、**落ちた原因は枚挙の消失で確定**。`cls_head` は意思決定分散の9割を担い（実測 A sd 7.49 vs B sd 0.78）、**MAIN決定内のクラスの77.3%は選択肢1個**＝クラスが決まれば答えも決まる。**「美しくする」と「現行と同等以上」を同時に満たす構成は存在しなかった**（joint=美しいが負ける / jcls=同等だが負債の返済ゼロ・パラメータ最多）

**【2026-08-17】two-tower の64軸制約は実在する。ただし効いているのは非MAINだけ**（[EXP-142](experiments/EXP-142.md)）: 内積は双線形なので状態と選択肢の相互作用が d_opt=64 本の軸に制限される。cross-encoder にすると **内積しか無かった ctx で明確に勝つ**（ctx15 DAMAGE **+12.8pt** / ctx30 DISCARD_ENERGY **+11.1pt** / ctx8 DISCARD +4.4pt。cls_head を残した jcls でも ctx30 は +11.1pt）。だが **ctx 8+15+30 は val 決定の 1.2%** しかなく全体では埋もれる。**予想外だったのは「同点決定」でも cross が負けたこと（−1.32pt）**: 同点の57.8%は「手札スロット違いの同一カード」で教師は99.5%で最小indexを選ぶため、**単純な規則は単純な形（双線形）の方が学びやすい**。なお two-tower を選ぶ本来の動機（アイテムを事前計算してインデックス化）を我々は享受していない（選択肢は5〜30個で毎回作り直す）＝**理屈は cross 側にあるのに実測は two-tower 側に付いた**

**【2026-08-17】稀にしか発火しない変更は「ベースと差分を同一シードで走らせ、進行が食い違った試合だけを取り出す」と測れる**（[EXP-141](experiments/EXP-141.md)）: 詰み層は発火が **0.075回/試合**しかなく、素の勝率比較（n=1200 で CI ±2.8pt）では原理的に検出できない。しかし**ベースと差分が当該ルール以外で完全に同一**なら、同一 `--engine-seed` で**発火しなかった試合は完全に同じ進行になる**。235 vs 222 と対照 222 vs 222 を各1200戦走らせると集計値は 0.5175 で完全一致するが、**game_index ごとの (winner, steps) を突合すると8試合だけ食い違い、その全てが「勝敗は同じまま手数が1〜5手減っただけ」**と特定できた（勝ちに変わった0 / 負けに変わった0）。**NN方策は `lethal_for_me` を特徴として持っているので既にほぼ自力で詰みを取っており、見逃した19試合もすべて勝っていた**。EXP-053 の「探索族で唯一生き残ったのは lethal-only」は**探索を持たない条件文方策での話**で、NN方策には当てはまらない

**【2026-08-17・最重要】val の差が大きく有意でも、プールの符号は保証されない**（[EXP-140](experiments/EXP-140.md)）: LSTM を丸ごと外すと（788,995 → **262,659**）val は **+0.62pt**（3シードとも同符号、**t=12.4**）、MAIN **+0.88pt**、**訓練-検証差が +0.0475 → +0.0106 と4.5分の1**（＝過学習が主因だったことの直接証拠。教師は5,309試合しかないのに789k〜1.3Mパラメータ）。それでもプール（v7・n=1200・CRN）は **72.10% vs 222の73.26% = −1.16pt**（L1×3の家族平均72.51%基準なら−0.41pt）。負けは**Marnie枠 −2.21pt（重み最大）と Kangaskhan枠 −4.58pt の2つに集中**し他7枠は横ばい。LayerNorm（val +0.42pt → プール −0.94pt）と同型のパターンが**効果量が桁違いに大きいケースでも再現した**。**「再帰が不要」ではなく「容量が不要」**でもある: 再帰だけ外して深さをMLPで戻すと利得の84%が消える（+0.10pt）。深さの単調傾向 L1>L2>L3>L4 は L0 まで続くが、それは val の話でしかない

**【2026-08-17】プール評価は `--pool` を明示する。既定は更新されていて黙って別の相手と戦う**（[EXP-140](experiments/EXP-140.md)）: `arena/pool.json`（既定）は上位2枠が新しいSLレプリカ（176_marnie_clean / 174_alakazam_clean、**合計49.1%の重み**）に差し替わっている一方、過去の数値はすべて `pool_v7.json`。指定を忘れると **errors=0 のまま比較不能な数字が出る**（実際に踏んだ: 239が64.58%と出て「−8.68ptの大敗」に見えたが、対面別を見たら上位2枠が別人だった）。**新しい数字が想定外に大きく動いたら、まず対面表を開いて相手が同じか確認する**。関連して **cuDNNのLSTMはビット再現性が無い**ので、同一シード・同一データでも run 間で val が約0.1pt 振れる（比較は必ず同一run内の交互順で行う）

**【2026-08-16・最重要】特徴を足す前に「既存の入力から復元できるか」を確かめる。ラベルを自分で復元できたなら、ネットワークにも復元できる**（[EXP-139](experiments/EXP-139.md)）: pointer network の選択肢塔は対象について位置と残HP比・エネ数しか持たず「種族」が入っていない（MAINでは cls_head の ATTACH_BUCKET が代役だが **Abra(741)とKadabra(742)が同一クラス 'abra_p'**）。対象カード埋め込み(+2,048)を足したが、狙い所（**正解クラスが同点の決定** val 6,011件）で **−0.03pt**（3シード、sd 0.59pt、t=−0.10。s1だけ+0.65ptでもs3は−0.60pt）、全体val +0.013pt で棄却。**機序は「学習ラベルを board の `ms{slot}_{種族}` one-hot + `inPlayIndex` から 100.0000% の精度で復元できた」ことそのもの**——復元できるなら情報は既に入力に在る。対象の正体は**欠けていたのではなく2つの塔にまたがって分散していた**だけで、内積が合成できる。**two-tower に穴があるように見えても「情報の欠落」か「因数分解のされ方」かを区別すること**。入力追加系はこれで4連敗（prev_opp −0.65pt / LayerNorm −0.15pt / featgen軸A / 本件）

**【2026-08-16】比較は「同一runで交互に回す」と交絡が消せる**（[EXP-139](experiments/EXP-139.md)）: 過去に測ったベースライン値を基準にすると当時のハイパラ差が交絡する。**同じデータファイルを読ませたままフラグだけ反転する `--no-target-emb` を足し、te_s1/base_s1/te_s2/… の交互順で1runに詰める**と、データ・前処理・系列順・ハイパラが完全一致し差はフラグのみになる。**交互順なので12h上限に当たっても対の比較が残る**。フラグが完全なno-opであることは「添付ファイルがある状態で切った時のvalが、ファイル無しと**小数15桁まで一致**するか」で検証する。派生配列を npz に足すときは **`max_game_len` の外れ値除去キー列に入れ忘れるとそこだけ行がずれて無言で壊れる**

**【2026-08-14・最重要】「教師の再現度」と「強さ」は同じ方向に動くとは限らない**（[EXP-132](experiments/EXP-132.md)）: ExItの補正を**ラベル品質で選別**すると保持データの一致率は **9.0% → 16.3%**（高品質部分集合では12.5%→39.1%）に倍増するのに、**対戦は vs186 で −1.25〜−3.17pt / プールv7 で 71.25%→70.29%** と悪化する。機序は**発火頻度**: 補正は**1試合あたり0.2〜0.3回**しか起きないのに、それを学ぶために方策全体（MAIN一致率 0.93→0.917〜0.925）を歪めている。しかも直せた補正は**賭け金の小さい局面に偏る**（EXP-125: 推測探索は乱択超えの信号の42%を拾うのにgapは2%）。**模倣学習では一致率↑＝強さ↑だったが（090→092で対壁+9.75pt）、発火頻度が低い補正ではこの関係が反転する。「発火頻度 × 効果量」が「方策全体を触る代償」を上回るかを先に見積もること**

**【2026-08-14】ExItの教師ラベルは9割がノイズ。質で選別すべきで、重み付けでは足りない**（[EXP-132](experiments/EXP-132.md)）: `R`（候補×M）は全候補が同一の`search_begin`から分岐したCRNペアなので**符号検定ができる**。実測: 全2,557件の不偏gap +0.0813 に対し、**p<=0.20 の610件は +0.3005 / p<=0.05 の265件は +0.4360（5.4倍）**。**量を増やしても効かない**（1,089→2,557件で保持一致率 9.2%→9.3%）のは増えた分もノイズだから。**硬い選別（捨てる）が最良で、弱いラベルを小さい重みで残す方式は効かない**（重みを下げてもノイズは勾配に入り続ける）。ただし**質×量は頭打ち**（610→1,130件で 16.3%→16.1%）

**【2026-08-14】Kaggleのdataset作成は非同期。readyを待たずにkernelを投げると落ちる**（[EXP-132](experiments/EXP-132.md)）: `push_sl.sh dataset` の直後に `kernel` を投げると `/kaggle/input` が空のまま起動し `train.npz not found` で ERROR になる（60MBで再現）。**`kaggle datasets status` が ready になるまで待ってから kernel を投入する**。また **ExItの局面指紋はバッチをまたぐと衝突する**（序盤の定型局面は別試合でもビット一致。2バッチ合算で多重ヒット927件、単体では0件）ので**索引をバッチごとに分ける**

**【2026-08-12・最重要】模倣可能性はアーキタイプに依存する。「メタ最強のデッキ」と「我々が模倣できるデッキ」は別物**（[EXP-127](experiments/EXP-127.md)）: Dragapult ex（440658e7e9）は最新メタで最も強い系統（4チーム×4リストが独立に60〜68%、対Marnie 68%/対Lopunny 63%。我々は43%/43%）だが、**MAIN一致率 0.62〜0.67 までしか模倣できない**（186 Alakazam は0.83）。**教師データを2.37倍（59,321→140,408決定）にしたら逆に −0.048 下がった**。訓練-検証差が +0.031→+0.019 と縮むだけで精度が上がらない＝**容量でも過学習でもなく、盤面要約から教師の選択が識別できない**（EXP-055「本人の選択は探索に条件付きでどの関数族でも識別不能」の再現）。**Alakazamが模倣できたのは「手札枚数＝打点」という観測可能なスカラーで勝ち筋が決まるから**で、Dragapultの判断の中心（Crushing Hammer/Jamming Tower/Lillie's の妨害タイミング）は相手の隠れ情報に条件付き＝EXP-125で殺したのと同じ壁に模倣の側から当たる。**乗り換え検討ではシェアと勝率の前に「勝ち筋が観測可能な量で決まるか」を見る**

**【2026-08-12】教師は team+sig+期間 で選ぶ。sig単位で束ねると方策が混ざって事故る**（[EXP-127](experiments/EXP-127.md)）: 同一デッキ 440658e7e9 でもチーム別勝率は **51〜67%** と幅があり、3チームを混ぜたら異なる方策の平均を1関数で近似することになって**どれにも当たらなくなった**（MAIN 0.6695→0.6215）。また**「個体勝率トップ」は切り出し方で簡単に化ける**: Mega Lucario 0c0f140f4f の「68.6%」は1チームの持ち分×4日窓の二重の上振れで、sig単位・全チーム合算では 63.5%→**58.3%**（n=1467）だった。**上位陣が一様に前週比+8〜9pt上がる**ような母集団変化も起きるので、**期間をまたいだ絶対値は比較できない。同一期間内の相対順位だけが使える**

**【2026-08-12・最重要】決定化ロールアウトは、隠れ情報を推測した瞬間に価値を失う**（[EXP-125](experiments/EXP-125.md)）: 同一600局面で、**真値の隠れ情報**なら独立24本のロールアウトで **+2.95pt/局面** [1.67, 4.23] 取れるのに、**手札／山／サイドの分割をサンプルしただけで +0.07pt** [−1.19, +1.33]（対応差 −2.88pt、**z=−5.05**）。相手のリスト読みが完璧という上限設定でこれ。一致率は 乱択36.1% < 推測43.0% < 真値52.5% で**乱択超えの信号の42%は拾っているのに gap は2%しか取れない＝当てられるのは賭け金の小さい局面だけ**。24サンプル平均でランキングが復元されないので**分散でなくバイアス**。**殺した範囲の境界を正確に引くこと: これは「終局まで打つロールアウト」を殺したのであって探索一般ではない。浅い探索は隠れ情報にほとんど依存しない**（EXP-053で探索族の唯一の生き残りが lethal-only だったのは、「今このターン倒し切れるか」が相手の手札を知らずに確定判定できるから）。**+9.45ptの余地のうち我々が取れるのは隠れ情報非依存の部分だけ**

**【2026-08-12・最重要】ExItの教師量は「生成した局面数」でなく「補正件数」で数える**（[EXP-124](experiments/EXP-124.md)）: 186で4,193局面をロールアウトして、重みが付いたのは **best≠top1 の1,089件（26.0%）だけ**。この量では**暗記しか起きない**——訓練側の補正一致率は 39.6% まで伸びるのに、**保持データは 9.2% で頭打ち**（2シードとも同一）。結果はプールv7で **70.4%（186の71.25%より −0.8pt）**、vs186 直接も4チェックポイント全てが50%割れで**棄却**。対戦成績の順位が**「186から動かないほど良い」**（最も汎化した step400 が最悪 −2.33pt）なのが機序の直接証拠で、暗記した補正は発火せず **best==top1 だった1,102局面を揺らす代償**だけが残る。**必要量は語彙の②と同じ物差しで測れる: 正例数 >= k×d_model（k=10 で2,560件）＝この教師データは最初から学習可能性の閾値未満だった**。補正1件あたり19秒なので1万件に53時間

**【2026-08-12】方策には まだ +9.45pt の改善余地が実在する**（[EXP-124](experiments/EXP-124.md)）: 186の貪欲手を決定化ロールアウトで選んだ手に替えると、その局面の勝率が **+9.45pt ±1.20（z=15.6）** 上がる。**前半12本でbestを選び後半12本で測る**二段構えの不偏推定で、素の平均 +16pt の **60%は選択バイアス**（EXP-117の61%が再現）。EXP-124が失敗したのは**教師量の問題**であって「伸びしろが無い」ではない

**【2026-08-12】決定的な再生を作るときは「割り当てを決める全パラメータ」を渡す**（[EXP-124](experiments/EXP-124.md)）: 自己対戦の再生が理論値の**1/3**しか一致せず、原因は相手のチャンク割り当てが**最大剰余法の分母＝総チャンク数**に依存していたこと（700試合=70chunk と 30試合=3chunk で order が別物になる）。**同一シードでも相手が違えば別の試合**という当たり前のことが、部分実行では静かに壊れる。**総数から逆算する量（最大剰余法・剰余巡回）を持つ生成器は、部分再生の入口で必ず事故る**。検証は「再生した系列を方策に流し、生成時に記録したスコアとビット単位で一致するか」で行う（実測 最大絶対誤差 0.000e+00）

**【2026-08-11・最重要】稀にしか非ゼロにならない特徴を標準化してはいけない**（[EXP-122](experiments/EXP-122.md)）: `z=(x−mu)/sd` は稀なカウント特徴で `sd≈√p` になるため **1単位あたりのz ≈ 1/√p が発散する**。実測: `os5_resist_vs_me`（ベンチ6番目が埋まること自体が稀）は **199.7σ**、状態異常フラグは62〜72σ、180で追加した稀な語彙11枚は4.6〜23.7σ（既存69枚は中央2.3σ）。**重みは中央値並みのまま**なので、発火した瞬間に既存語彙の5倍の寄与を注入する。**104から186まで全モデルに存在した欠陥**。対処は clip でなく**符号化の修正**: 0/1フラグは標準化せずそのまま、`opp_seen` は **x/4**（同名4枚まで。**ACE SPEC は x/1**）、`noeffect_e` は x/3。**`pool_`/`left_` は 4→3→2→1→0 と必ず全域を通るので 1/sd=2.0 と健全＝触らない**（「有界か」でなく「**1/sd が大きいか**」で選ぶ）。効果は「壊れている時だけ」出る: 語彙81枚では **+0.73pt**（対Kangaskhan +6.9pt）だが、稀な列が少ない174の語彙では −0.17pt

**【2026-08-11】特徴の選抜を「観測平均(mu)」で切ってはいけない**（[EXP-122](experiments/EXP-122.md)）: **mu = 正例率 × 観測時の平均枚数**で、後者（相手が何枚積んでいるか）は学習可能性と無関係。実測で1.00〜3.47倍の幅があり、**Festival Grounds(正例4,486)が却下されDipplin(正例4,445)が採用される逆転**が起きていた。代わりに **正例数 >= k × d_model** で測る（1列は enc.0 で隠れ256ユニットへ繋がるので256本の重みを推定する。その1本あたりの標本数）。**モデル容量に紐づくので恣意性が小さい**。174の語彙69枚は最小4,445正例＝1本あたり17.4で、k=17ならほぼ同一集合が再現される

- **他Kaggleシミュコンペ（Hungry Geese/Halite/Connect X）の上位解法はNN+MCTS+自己対戦の多段学習だが、それらはほぼ完全情報ゲーム**。我々が試して不発だったのはこの定番路線で、713608も同結論（強い既存ヒューリスティック＋CRN無し高分散評価は定番手法の不得意領域）。**PTCGは不完全情報なのでStratego/ポーカー系（ISMCTS/ReBeL/信念状態探索、arXiv 2007.13544・2511.07312）が理論的正解**だが重量級で713608のISMCTSも頭打ち。評価ノイズ削減(CRN)はエンジンがシード非対応で構造的に不可能。→**安易な勝ち筋はなく学習系はL優先の長期投資のまま**（Web調査 2026-07-07）。**【2026-07-20更新: CRN不可は失効】** 7/1エンジンC++ソース公開+7/6運営が改変利用を許可（[discussions/717141](../discussions/717141-engine-source-released.md)）。libcgは自前ビルド済みのためRNGシード注入APIの追加ビルドでCRN（共通乱数ペア評価）が解禁可能=EXP-016/学習系凍結の死因（評価分散）が原理的に除去できる。検証はI-122 Step0（同一シード×決定的方策2回でログのバイト一致）
- 我々の探索4連敗（EXP-006/008/009/012）は文献の既知の失敗モードと一致: **strategy fusion**（決定化ごとに隠れ情報に依存した別戦略を選ぶ）と**fake omniscience**（自分の山札順・相手の手札を知っている前提の楽観）。正攻法はISMCTS/EPIMC（情報集合を保つ・完全情報化を遅延）で、lethal限定探索が機能したのは「全決定化一致」要求がstrategy fusionを排除するため（I-030参照）

- **探索は評価関数が律速**。決定化1手先+自ターン末の静的盤面評価は、調整済みヒューリスティックより一貫して弱い（ベースに44.5%、[EXP-006](experiments/EXP-006.md)）。相手の返しを見ない即物評価が長期価値（温存・育成・ガード）を壊す
- 探索のコストは問題にならない: 決定化2サンプル×4候補×ロールアウトで9.3ms/手。600秒/ゲーム予算に対し余裕4桁（[EXP-006](experiments/EXP-006.md)）
- **探索の安全な使いどころは評価関数が不要な確定局面**。lethal限定探索（サイド3以下・全サンプル勝利のみ上書き）は発火0.7%と薄いが発火ゲーム敗北0、構造上ベース同等以上（[EXP-007](experiments/EXP-007.md)）
