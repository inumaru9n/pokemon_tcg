# 模倣の外に何が残っているか（117基準・2026-08-04の実測）

対象: 117_alakazam_dspline（プールv5 60.59%、104比 +2.91pt有意、提出済み sub 55235376）

## 0. 前提が変わったこと

**EXP-106 で run_pool をCRN対応にし、対応差のCI幅が ±2.7pt → ±0.35pt（7.7倍）になった。**
これは「小さな確定的改善」の採否計算を変える。従来は +1pt の変更を測れず、
EXP-049 の効果量法則（頻度×効果 < ノイズ床なら着工しない）のノイズ床が高すぎた。

## 1. 117 はどう負けているか（新規実測）

| 対面 | 敗因の内訳 | 試合長 | 負け時の残サイド中央値 |
|---|---|---|---|

（059時代の統計）。現在の支配的敗因は**プライズレースの僅差負け**。

### 機序（vs Marnie）

```
自分のターン 7.6回/試合、そのうち**攻撃したのは52.0%** ＝ 約4回しか殴れない
取ったサイド 4.05枚/試合（1枚KO 88回 + 2枚KO 37回 / 40試合）
→ 6枚に**構造的に届かない**。負け時の残サイド中央値2はこれと一致する
```

相手（Marnie）は Froslass 等で**1プライズ盤面を長く維持できる**（domain expert のコメント、

攻撃できるターンを増やすかのどちらか**が唯一の勝ち筋。

## 2. 強化学習の見込み — **低い（着工しない）**

| 事実 | 出典 |
|---|---|
| 方策が極端に尖っている: 選択肢平均8個（最大エントロピー ln8=2.08）に対し**T=1.0でも0.406** | EXP-095 |
| 探索温度 T=0.7（採用値）で argmax比 **−3.7pt**、argmaxと違う手は約9手/試合 | EXP-095 |
| 同じ発想の粗い版（クラスバイアス空間のSPSA、40iter収束）は**利得ゼロ** | EXP-079 / I-122 |
| ルールマイニングの残差は「順序等価ノイズ」＝模倣はほぼ天井 | EXP-056 / I-110 |
| Stage 2b（KL係数スイープ）は**未実行**＝反証されてはいない | EXP-095 |

**PPOは「まず3.7pt損してから取り返す」構造**。加えて KL錨と低エントロピーが両方
「変わるな」に働く。粗いパラメタ空間で平坦だったことは豊かな空間の平坦を証明しないが、
**残り12日で GPU オンポリシー生成を回す投資に見合う事前確率は低い**。

## 3. 価値関数の直接利用 — **閉じている**

EXP-104: V は試合単位AUC 0.944（サイド差0.890を上回り、序盤では+21pt）だが、
**教師の良手ですら ΔV>0 は52.2%＝コイン投げ**。原因はラベルが試合の勝敗で、
同じ試合の全決定が同じラベルを共有すること。**入力を変えても直らない**。
min_margin=0 で 300戦0勝。

## 4. テンポ／クロック探索 — **素朴な版は本日棄却。精密版に余地**

「サイドを引けるまでのターン数」を目的関数にする案を実装して測った。

```
clock = op_ttp − my_ttp
  my_ttp = 0(今KO可) / ceil(相手アクティブ残HP / 自分の最大打点) / ∞(打点0)
  op_ttp = 同様に相手視点
```

### 検定1: 予測力 — **自明なサイド差に負ける**

| | clock AUC | サイド差 AUC |
|---|---|---|
| 序盤 | 0.658 | 0.652 |
| 中盤 | 0.840 | **0.867** |
| 終盤 | 0.810 | **0.969** |

（参考: 学習V は 0.944、序盤でサイド差を +21pt 上回る）

### 検定2/3: 分解能と変更率 — **8割が縮退**

| | 値 |
|---|---|
| 候補間で clock が動く決定 | 40.0% |
| └ **∞センチネル起因**（＝「今打点のある技があるか」を測っているだけ） | **77.8%** |
| └ 実質的なテンポ信号 | **8.9%** の決定 |
| 素朴な clock-argmax が方策を覆す率 | 25.1%（**過大。進化も逃げも潰す**） |

**素朴なクロックで方策を上書きしてはいけない。** 8.9% は search_probe の基準では
「5〜15%＝適度」の帯だが、**そこで方策が誤っている証拠はまだ無い**。

### ❌ エネ過剰付与は存在しなかった（測定誤りの訂正）

初報の「1.77回/試合」は**貼り先を区別せずに数えた誤り**だった。
「アクティブが充填済みのときにエネを貼った」を数えており、その大半は
**ベンチに貼っていた＝正しい手**。貼り先で分けると:

| vs Marnie（40試合） | アクティブへ | ベンチへ |
|---|---|---|
| アクティブが**充填済み** | **0.03回/試合** | 1.93回/試合 |
| アクティブが未充填 | 1.70回/試合 | 0.53回/試合 |

**充填済みでアクティブに重ねたのは40試合で1回だけ**（vs Spidopsも同じく1回）。
「充填済みでアクティブにもベンチにも貼れた」場面は10.18回/試合あるので、
**方策はその全てで正しくベンチを選んでいる**。

実装した 125（アクティブへの重ね貼りを禁止）は**9.47回/試合発火するが方策の1位を
覆した回数は0/284＝完全な空振り**だった。

**教訓: 「非効率がある」と主張する統計は、介入した版の発火統計で必ず裏を取る。**
統計カウンタ（seen/blocked）を最初から入れていたので1回の実行で判明した。

### 参考: 元の仮説の根拠（機序自体は正しかった）

**Alakazam の Powerful Hand はコスト {P}（1個）で、打点は手札枚数に比例しエネ枚数に依存しない。**
したがってAlakazamへの2個目以降のエネは（逃げ以外に）**完全に無駄**。
エネ付与は1ターン1回なので、1.77回/試合の無駄は**自分のターン7.6回中の23%を捨てている**ことになる。
これは §1 で特定した「攻撃できるターンが足りない」という敗因に直接効く。

## 6. 結論と推奨

```
強化学習（PPO/リーグ）    着工しない  — 3.7ptの前払い + 粗い版が利得ゼロ + 残り12日
価値関数の直接利用        閉じている  — ΔVの分解能が原理的に無い（EXP-104）
素朴なテンポ探索          棄却        — 予測力がサイド差以下、8割が縮退（本日）
確定信号のうち低頻度      見込み薄    — lethal/KO見送りは0.3回/試合台
~~エネ配分の効率化~~      **❌ 棄却**  — 非効率は存在しなかった（0.03回/試合）。測定誤り
```

**修正後の結論: 機械的な非効率は既に無い。**
エネ配分・詰め・KO判断はいずれも方策が正しく処理しており、
残る差は複数ターンにまたがる戦略——模倣が教師を超えられない領域。
**本日の唯一の成功（デッキ構築 +2.91pt）が示すとおり、
残り期間の期待値は「方策の外側（デッキ）」の方が高い。**
