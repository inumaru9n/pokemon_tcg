# 724187 — Things I tried that didn't work（PokéForge技術ポストモーテム・2026-07-09）

## 3行サマリ

- 90本の実験レポートを持つチームの失敗記録。**「自作の手法は弱いエージェントを大きく改善するが、
  成熟した公開方策には届かなかった」**が結論
- **最大の利得はデッキ修理（0.6%→9.2%）で、方策は一切変えていない**
- **「高権限の上書き（high-authority overrides）は有害」**（26.2%→21.2%→20.0%と単調に悪化）

## 取れる情報

★★★ **結果マップ**（同チームの実測）:
| 領域 | 最良の結果 | 判定 |
|---|---|---|
| ランダム相手のベースライン | 66.0% WR | スモークテストにしかならない |
| 実参照ベースライン | 160中1位、調整後 0.6% WR | これが本当の出発点 |
| **デッキ修理** | **0.6% → 9.2%** | **方策を変えずに大きな実利得** |
| ヒューリスティック調整 | 13.2% | 有効、その後頭打ち |
| ターンレベルの計画 | 20.0% | 構造的な利得は本物 |
| 加法的プレイブック | ミラー35.0%（ベース26.2%） | 効いたが事前設定バーに届かず |
| **高権限の上書き** | **26.2% → 21.2% → 20.0%** | **有害** |
| 自立した模倣 | 不一致<8% | それでもミラー同等に届かず |

★★ **制約の整理**（我々の環境認識と一致）:
- ローカルの相手プールは不完全 → **候補のスクリーニングはできるが決着はつけられない**
- 現行トップメタの方策はコードとして入手できない → **天井を決める相手に対して訓練できない**
- 確率的なゲーム → **小さな利得には大標本か対応のある評価（paired evaluation）が要る**
- Kaggle実行環境がローカルと違う → **ローカルの成功は提出の妥当性を意味しない**

## 注意点・我々への含意

- **「高権限の上書きは有害」は我々の実測と一致**: EXP-053（探索でENDを上書きすると特に有害）、
  EXP-104（Vで方策を上書き→300戦0勝）、EXP-105（打点0ルール→加重+0.35ptのみ）。
  **方策を強い権限で覆す形は一貫して負ける**
- **「デッキ修理が方策を変えずに最大の利得」は、いま進行中の 112/113（デッキ枚数変更）を支持する**。
  ただし彼らの出発点は0.6%＝壊れたデッキで、我々は既にトップ個体の構築を使っているので
  同じ倍率は期待できない
- 「小さな利得には対応のある評価が要る」は EXP-106（run_pool のCRN対応）と同じ結論に
  独立に到達している。**我々は道具として実装済み**
- 未検証: この投稿の勝率の定義（"adjusted WR"）が不明で、我々の数字と直接比較できない
