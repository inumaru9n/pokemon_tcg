# 740956 — [24th Place] A Population-Based Reinforcement Learning Ecosystem（votes 20・2026-09-12・**最終24位**・1128.5）
チーム "Boss's Orders Are All You Need"。実装サンプル公開: https://github.com/ymgaq/ptcg-population-rl

## 3行サマリ

- **リプレイ100〜1,000試合 → GBDT(LambdaRank)で教師方策 → その教師で15,000〜30,000試合を自己生成 →
  1MパラメータTransformerへ蒸留 → population PPO（相手20〜40種）** という4段パイプライン
- **小モデルを選んだのは意図的**（1M級・C++ OpenBLAS/AVX2で32トークン1ms）。
  64vCPU で **5,000試合を30〜40秒**。多数のデッキ・方策を同じ期間内に回すため
- 評価は **320エージェント・約220万試合**を蓄積し、ベイズレーティング + 勝率プロファイルのクラスタリング

## 取れる情報

★★★ **我々の到達点（GBDT教師 → NN模倣）は、彼らのパイプラインの最初の2段そのもの**。
彼らはそこから「教師に自己対戦させてデータを増やす」→「PPO」と進んだ。差は着想ではなく**続きを走ったか**

★★★ **Transformerを小リプレイ集合で直接学習すると、記録された手は再現できるが他エージェントに弱い**
（教師が訪れた状態が少なすぎる）。だから**まずGBDTで「遊べる方策」を作り、それに試合をさせて状態分布を広げる**。
GBDT教師は最終PPOモデルの約200レーティング下、しかしRL初期マイルストーンまでの時間を50〜80%短縮

★★★ **相手の隠し手札・山は入力にしない**。自分の山/サイドも「belief（初期デッキ−観測）」として推定値で渡す。
**再帰メモリなし**（現観測のみ）で 1M パラメータ・6層・128次元・最大120トークン

★★ **アーキテクチャ**: 盤面も選択肢も**同じ系列のトークン**にして self-attention（Global1 + Board12 + Zone6 +
Option100 + STOP1）。Policy は pointer（Globalからquery、Option/STOPのkeyと内積 + 候補バイアス）。
複数選択は**選択済みトークンの和 + ステップ埋め込みで条件付け**た逐次選択。
Value は −1〜+1 の**51支点の分布**（PPO/GAEのcritic用。探索には使わない）

★★ **Option側に「行動結果特徴」32次元**（ダメージ・KO・取得サイド・資源変化など公開情報から計算可能なもの）。
不確実な効果は「確定」ではなく**適用可能性と不確実性**として表現

★★ カードIDは**自デッキ限定の最大32語彙**に写像（全カード埋め込みを持たない）。読み込み時にID/枚数を照合

★ **学習実装とC++推論の一致検証**を明示（同じ重みでも候補順やマスクが違えば別方策になる）。
我々の「argmax一致100%検証」と同じ規律

★ ルールベース方策も同じパイプラインに接続して蒸留できる（リプレイが乏しいデッキ向けの補助経路）

## 我々への含意

  我々の模倣は常に「教師が実際に訪れた局面」だけで、そこから外れた局面は未学習のまま本番に出ていた
